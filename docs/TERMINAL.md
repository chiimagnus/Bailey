# 终端与窗格

修改会话、停靠布局、分屏或焦点时，保留以下约束。

## 生命周期与布局

- 一个终端会话持有一个长生命周期进程与表面。切换项目、拖动标签或重挂载只移动现有表面，不新建 Shell，不丢选区、滚动与查找状态。
- 外层停靠和标签内部窗格是两套布局，各有状态真源。diff 保持独立标签；统一/并排属于 diff 显示，不是内部终端分屏。
- 每个标签组地位相同，使用相同的「＋」入口；工具面板移动而非重复创建。默认三列只是初始布局。
- 布局按项目保留。移动与关闭后焦点必须落在有效内容；放大窗格不销毁原分屏树，取消放大恢复布局。
- 关闭窗格只结束其内容；关闭整个工作标签结束其中全部窗格。关闭工具面板不删除项目或会话。

## 输入、搜索与通知

SwiftUI 接收交互，AppKit/Ghostty 处理终端表面、输入和原生焦点；不要以重建表面修复焦点。

命令面板的文件搜索仅支持本机项目。SSH 目标不得搜索本机同名目录；选择结果后应完成真实打开或会话聚焦，不能只验证命令已派发。

通知使用对应项目名称，保留程序正文；点击须定位发出通知的会话。关闭与重启不能承诺恢复运行中的命令，恢复边界见[设置与恢复](SETTINGS.md)。

## 验证重点

实际检查多项目切换、外层拖动与内层分屏、关闭后焦点、放大恢复、快捷键与通知定位。终端进程不得因重挂载重启，后台命令不得意外中断。

模型布局检查不能代替原生焦点与输入验收；浏览器和未保存文件重挂载另见[浏览器](BROWSER.md)与[编辑器](EDITOR.md)。
