# 终端与窗格

在项目中运行 shell 或代码智能体，并把终端、文件和浏览器并排放在同一个标签页里。

## 启动会话

选中左侧项目，按 ⌘T。本地项目启动本机 shell，SSH 项目启动远程 shell。
代码智能体作为普通终端程序运行；它产生的文件修改可在[Git 面板](GIT.md)检查。

按 ⌘P 打开命令面板，查找命令、文件或已有会话。
按 ⌘F 查找当前终端内容；按 ⌘K 清理当前终端显示。

## 分屏与焦点

- ⌘D 在右侧新建终端窗格，⇧⌘D 在下方新建；其他方向在“标签页”菜单中选择。
- 文件和网页可通过各自的“在旁边打开”入口放入窗格，见[文件](EDITOR.md)和[浏览器](BROWSER.md)。
- ⌥⌘方向键移动焦点；⌘[ 和 ⌘] 在窗格之间轮换。
- ⇧⌘↩ 放大当前窗格，再按一次回到原布局；“标签页”菜单还可均分和调整窗格大小。

差异查看器当前使用独立的单窗格标签，不支持把 diff 分屏或拖入混合窗格。统一/并排差异是 diff 自身的布局，不是终端分屏。

## 关闭与通知

⌘W 关闭当前窗格；它是标签中的最后一个窗格时，标签也随之关闭。
关闭终端会结束该会话，重要命令先结束或自行妥善托管，再关闭窗格。重启不会接着运行这些命令。

终端通知需要 macOS 通知权限。通知标题使用左侧对应项目的名称，正文保留终端程序原有提示；点击通知可回到发出通知的会话。看不到通知时先检查系统对 Kero 的通知设置。

## 查看会话与服务

按 ⇧⌘I 打开信息面板，查看会话、进程与监听端口。端口打开方式见[浏览器与服务](BROWSER.md#打开开发服务)。
终端字体、光标、Option 键和历史恢复见[设置与恢复](SETTINGS.md)。历史恢复只能回看输出，不能恢复运行中的进程。
