# 终端与窗格

在项目中运行 shell 或代码智能体，并把终端、文件、浏览器以及项目、信息、Git 面板放在需要的位置。

## 启动会话

选中左侧项目，按 ⌘T。本地项目启动本机 shell，SSH 项目启动远程 shell。
代码智能体作为普通终端程序运行；它产生的文件修改可在[Git 面板](GIT.md)检查。

按 ⌘P 打开命令面板，查找命令、文件或已有会话。
文件搜索仅支持当前本机项目；SSH 目标不显示同路径的本机文件。远程文件从文件面板打开。
按 ⌘F 查找当前终端内容；按 ⌘K 清理当前终端显示。

## 分屏与焦点

- ⌘D 在右侧新建终端窗格，⇧⌘D 在下方新建；其他方向在“标签页”菜单中选择。
- 文件和网页可通过各自的“在旁边打开”入口放入窗格，见[文件](EDITOR.md)和[浏览器](BROWSER.md)。
- ⌥⌘方向键移动焦点；⌘[ 和 ⌘] 在窗格之间轮换。
- ⇧⌘↩ 放大当前窗格，再按一次回到原布局；“标签页”菜单还可均分和调整窗格大小。

差异查看器保持独立标签，不会与终端内容合并为同一个内部窗格；但可以把其完整标签拖入工作区分屏。统一/并排差异是 diff 自身的布局。

## 自由停靠布局

- 拖动标签到另一个标签栏或内容中央：合并到同一标签组；拖到已有标签附近可排序。
- 拖到窗格内容的上、下、左、右边缘：生成相应分屏，只预览最终落点。可继续嵌套分屏。
- 拖动分隔线调整宽度或高度；双击分隔线不触发复位。布局按项目保存，重启后恢复。
- **每个标签栏的「＋」**都打开相同的弹窗：新建终端、项目、信息、文件、Git。新建终端直接放入该标签组；已有面板移动到该标签组，不会重复创建。
- 默认显示三列，但所有标签组地位相同，都能继续上下左右拆分、合并和关闭。项目、文件、Git、信息跟随当前项目；关闭工具标签只移除面板，不删除项目或终端。

## 关闭与通知

鼠标悬停在标签上时，左侧图标变为 ×，点击可关闭整个标签（含其中的分屏）。⌘W 则关闭当前窗格；它是最后一个窗格时，标签也随之关闭。
关闭终端会结束该会话，重要命令先结束或自行妥善托管，再关闭窗格。重启不会接着运行这些命令。

终端通知需要 macOS 通知权限。通知标题使用左侧对应项目的名称，正文保留终端程序原有提示；点击通知可回到发出通知的会话。看不到通知时先检查系统对 Kero 的通知设置。

## 查看会话与服务

按 ⇧⌘I 打开信息面板，查看会话、进程与监听端口。端口打开方式见[浏览器与服务](BROWSER.md#打开开发服务)。
终端字体、光标、Option 键和历史恢复见[设置与恢复](SETTINGS.md)。历史恢复只能回看输出，不能恢复运行中的进程。
