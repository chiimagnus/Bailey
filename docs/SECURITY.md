# 安全与漏洞报告

本仓库维护本地构建、签名的 Kero，没有自动更新或公开二进制发布渠道。
本文负责漏洞报告方式和安全边界；这些方式或边界变化时须同步更新。

## 报告漏洞

先联系[仓库维护者](https://github.com/chiimagnus)，确认私下报告渠道。
报告包含复现步骤、受影响构建及 macOS 版本。修复前不要在公开议题中披露漏洞，也不要附带密钥、令牌或私人终端输出。

Kero 的终端集成、剪贴板及远程操作问题在此报告。
Ghostty 本身的漏洞请联系 [Ghostty 安全团队](https://github.com/ghostty-org/ghostty/security)。

## 使用与维护边界

- 终端程序读取剪贴板须经确认；远程程序的输出不能绕过此边界。
- SSH 项目使用已有 OpenSSH 配置和密钥。主机信任失败时，先在终端确认身份，不要关闭主机校验来消除报错。
- 远程删除不会进入本机废纸篓，执行前确认路径和备份。
- 恢复终端历史为可选功能，启用后输出会保存到磁盘；其中可能包含敏感信息。
- 端口转发向 SSH 请求仅监听回环地址；远端服务的 `GatewayPorts` 设置可能改变监听范围，需由远端管理员确认。
