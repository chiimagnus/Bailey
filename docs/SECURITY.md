# 安全

修改终端输入输出、SSH、文件删除、转发或持久化时，保留以下信任边界。

- 终端程序读取剪贴板须经确认，远程程序输出不能绕过此边界。
- SSH 使用已有 OpenSSH 配置与密钥；主机信任失败不得通过关闭校验绕过。
- 远程失败不得回退写入本机。删除远程文件不进入本机废纸篓，确认范围与备份，不描述为可从本机恢复。
- 端口转发向 SSH 请求仅监听回环地址；远端 `GatewayPorts` 可改变监听范围，不能把请求地址当作服务端保证。
- 终端历史是可选磁盘持久化，可能包含敏感输出；性能 trace 也可能含内容与路径。不得默认启用采集或提交私人数据。
- 测试使用临时数据与专用连接，不借用用户 SSH master，不破坏真实工作区。应用替换和授权按 [AGENTS.md](../AGENTS.md) 执行。

## 漏洞处理

先联系[维护者](https://github.com/chiimagnus)确认私下渠道。报告保留复现步骤、构建与 macOS 版本，不附密钥、令牌或私人终端输出；修复前不公开漏洞细节。

Kero 的终端集成、剪贴板和远程问题由本仓库处理；Ghostty 内核漏洞联系 [Ghostty 安全团队](https://github.com/ghostty-org/ghostty/security)。
