# 浏览器与开发服务

修改浏览器导航、重挂载或服务打开方式时，保留以下约束。

## 浏览器状态

浏览器标签持有 WebView。切换项目、移动停靠标签或 SwiftUI 重挂载复用同一实例，保留页面、表单、滚动与前进后退历史；不要在 View 创建时重新导航。

地址输入区分明确网址、主机名和搜索词。搜索词发送给 Google，不应把私人终端内容自动填入搜索。链接的新标签与系统浏览器入口各自完成对应动作。

跨进程恢复只重新打开保存的网址，不承诺恢复网页运行状态或表单，见[恢复约束](SETTINGS.md#快照与恢复)。

## 开发服务与隧道

浏览器通过用户输入的网址访问开发服务。远端服务需要转发时，在设置中添加并启用[长期隧道](SETTINGS.md#长期隧道)，再使用配置的本机地址；隧道独立于终端和浏览器标签，不由页面导航创建。

交互 SSH 的文件与 Git 操作只使用现有 master，失联后不得悄悄新建认证连接。长期隧道的启动、认证与回环监听边界见[安全](SECURITY.md)。

## 验证重点

原生重挂载检查须核对页面内容、未提交表单、滚动与前进后退历史，不只比较对象身份。长期隧道按设置文档验证，不把页面加载成功等同于 SSH 连接或隧道正常。
