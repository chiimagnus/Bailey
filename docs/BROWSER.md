# 浏览器与开发服务

修改浏览器导航、重挂载或服务打开方式时，保留以下约束。

## 浏览器状态

浏览器标签持有 WebView。切换项目、移动停靠标签或 SwiftUI 重挂载复用同一实例，保留页面、表单、滚动与前进后退历史；不要在 View 创建时重新导航。

地址输入区分明确网址、主机名和搜索词。搜索词发送给 Google，不应把私人终端内容自动填入搜索。链接的新标签、新窗格与系统浏览器入口各自完成对应动作。

跨进程恢复只重新打开保存的网址，不承诺恢复网页运行状态或表单，见[恢复约束](SETTINGS.md#快照与恢复)。

## 服务与转发

- 信息面板列出的本地监听端口在系统浏览器打开，不隐式创建内嵌浏览器标签。
- 远程端口先建立到本机回环地址的转发，再打开或复制本机地址；本机端口可不同于远端，以实际返回值为准。
- 会话端口转发由连接持有，重复或并发请求复用同一结果，不由工具 View 持有。面板移动不取消，连接断开后旧请求不得发布成功。
- 会话转发和[独立长期隧道](SETTINGS.md#长期隧道)生命周期不同。SSH master 消失后不得为检查或转发悄悄新建认证连接；监听边界见[安全](SECURITY.md)。

## 验证重点

原生重挂载检查须核对页面内容、未提交表单、滚动与前进后退历史，不只比较对象身份。服务检查覆盖重复/并发转发、端口占用、连接在途断开、master 消失，以及真正能访问的返回地址。
