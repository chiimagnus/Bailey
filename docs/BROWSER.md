# 浏览器与开发服务

在工作区中查看网页，或打开终端启动的本地、远程服务。

## 打开网页

1. 选中项目，从“文件 → 新建浏览器标签页”打开浏览器。
2. 在地址栏输入网址并回车。
3. 需要并排查看时，在网页链接右键菜单中选择新窗格；也可打开新标签页。

地址栏支持完整网址、主机名和搜索词；普通搜索词会交给 Google 搜索，注意不要输入密钥或私人终端输出。
开发服务建议填写明确地址，例如 `http://localhost:3000/`，避免猜错端口或协议。

## 常用操作

- ⌘L 聚焦地址栏，⌘R 刷新；加载时可停止，工具栏支持前进和后退。
- 网页链接右键菜单可在新标签页、新窗格或系统默认浏览器打开。
- “浏览器 → 在默认浏览器中打开”把当前页面交给系统浏览器。

## 打开开发服务

按 ⇧⌘I 打开信息面板。点击列出的本地监听端口，会在系统默认浏览器打开服务；要在 Kero 内查看，可复制地址再粘贴到地址栏。

对于信息面板列出的远程会话端口，打开或复制地址会先建立到本机回环端口的转发，再使用本机地址。重复操作复用该连接的转发；本机端口可能不同于远端端口，以显示或复制的地址为准。
这种转发依赖对应 SSH 连接，不等于独立的长期隧道。需要跨标签使用的转发时，见[设置中的端口转发](SETTINGS.md#端口转发)。

## 遇到问题

- 页面失败：检查地址、服务是否监听、网络和页面上的错误，再决定重试或交给系统浏览器。
- 远程服务打不开：先检查 SSH 连接与转发错误，不要直接把远端 `localhost` 当成本机服务。
- 重启会重新打开保存的网址，不恢复页面里未提交的表单或运行状态；离开前先保存网页中的工作。
