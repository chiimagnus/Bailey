# 差异查看与编辑

工作区、暂存区和历史提交共用原生 Diff，只有工作区可写。
文件菜单的 ⌥⌘U 切换 Unified／Split，显示下一目标布局；
优先当前展示的有效 Diff，否则使用当前项目最近的有效 Diff；
尚未加载、纯历史原文或没有有效差异／编辑状态时不参与。
本页维护差异算法、折叠、行装饰和工作区编辑；共用文本契约见 [原生编辑器](editor.md)。

## Invariants

- **严格区分来源与原字节。** 暂存区、历史只读；工作区原始文本与 Git 规范化文本分开。
- **只有一个可写原生缓冲。** 从首帧起使用同一 TextKit 2 文档，隐藏上下文与删除行仅改变布局。
- **折叠不改正文。** 展开仅由明确操作触发，手动展开锚定真实 Git 基线。
- **真实布局与坐标一致。** 两列保持对应，滚动、命中和无障碍按实际视口及原文索引。
- **过期查询不覆盖新编辑。** 保存、重挂载、取消和关闭保护真实内容及原生 Undo。

比较来源、编码、Git clean filter、LFS 与原始字节读取由 [Diff 数据来源](diff-content.md) 维护。

## 原生渲染

原生表面属于 `DiffTab`。切换项目或重挂载不得丢失编辑、撤销和滚动。
有变更的文件必须先完成差异计算再显示，不得首帧展示全文、下一帧才折叠。
接受新文件快照时，同步失效旧折叠、行装饰并更新展示版本，
不得让旧折叠行号查询新正文的 UTF-16 行索引；Git 基线不变时保留 Split 左栏，
基线变化时才撤销旧左栏内容；读取失败仍保留上次成功的展示。
Git 文件读取和折叠计算是同一次展示准备：前者完成、后者尚在运行时，
再次点击同一 Changes 文件或首次挂载视图不得重读、取消或延迟尚未完成的差异。
无变更文件可直接编辑，已有编辑焦点和未保存文本不会被等待中的计算隐藏。
原生编辑器一旦挂载，
失焦自动保存、手动保存及 Git 重载均不得因投影暂时失效而卸载编辑器。
插入／删除真实行后即按 UTF-16 和 Git LF 行坐标更新折叠与删除占位，
不等待后台差异计算或依赖视图重建；没有折叠的可编辑文件也要立即更新行号。
编辑隐藏行不能顺带展开其余未修改上下文，实际改变的行由当前版本差异计算显现。
Split 基线同步更新；手动展开的行区间锚定不可变 Git 基线，而非 Diff 块序号，
编辑拆分未修改区间时保留原来展开的行，并继续隐藏未被展开的上下文；
保存及重读同一 Git 基线时保留展开状态，基线更换时才清除旧锚点；
不引入第二份可写正文、焦点驱动的 Review/Edit 呈现或持久化模式偏好。

### 差异计算

`DiffEngine` 计算行级及行内差异；大范围重复文本先尝试有编辑距离预算的精确匹配，
没有唯一锚点且两侧行数相等时，还会验证相同位置的连续未修改行，
仅对其间的变更重新计算，避免将数百处小改动误判成整篇删除再新增。
无法确认对齐的区域仍按实际内容显示为变更，不凭哈希推测相等。
Split 左侧只更新变化文字与语法属性，不因右侧编辑或焦点交接重置整个文档；
缺失行占位直接来自差异块，不另生成全文基线。
每个变更块仅计算一次词级差异，Unified、Split 和编辑装饰共用结果。
密集逐词差异先用两侧不可避免的更改长度下界判定是否都超过噪声阈值；
可确定无有效逐词强调时不再构建 Myers trace，保留共享词、Unicode 和阈值边界的精确着色。
仍需计算时在 Myers 循环和行对投影中检查取消，避免过期显示任务持续占用 CPU。
普通工作区首次展示复用经过对象 ID 和快照校验的 Git patch 行操作；
不能映射的来源仍使用原有算法，后续实时编辑也由可取消的行级算法计算，
不能用过期 Git 行号覆盖编辑缓冲。

### 语法颜色与装饰

`DiffSyntaxHighlighter` 使用编辑器同一语法与主题，
只读差异的两侧源码由 Tree-sitter 完整解析以保留多行语法上下文，
但只查询折叠后实际展示的源码区间，不再扫描数万行隐藏内容。
可编辑 Worktree 的新侧由原生 Neon 实时着色，不再重复执行离线解析；
旧侧仍用于删除行和 Split 基线着色，Git clean filter 规范化对照保留双侧解析。
同一标签的两侧独立保留字节完全一致的解析树，手动展开时重新查询当前可见区间而不重新解析；
源码字节或语言变化后才重建语法树；`DiffSyntaxSource` 按字节身份核对，
独立缓冲区逐 UTF-8 字节比较，不用 Unicode 规范等价判断。每侧最多缓存 5 MiB 的原文及解析树，
超过上限不保留树；真正关闭 Diff 标签时释放各侧语法缓存。
旧／新两侧在后台并行捕获，语法查询编译可与 Git 读取重叠。
主线程只在对应只读布局真正显示时创建富文本，不为隐藏的统一／分栏布局预建三份着色文档。
工作区源码与历史只读源码共用 TextKit／Neon 语法插件；工作区删除行沿用暂存区旧侧的语法颜色与词级强调色。
统一和并排 Diff 均仅在行号栏使用红绿行背景及增删标记；正文使用主题背景，仅对实际词级差异着色，不绘制变更区块边框。
并排对齐的无内容占位行仍保留中性斜纹，原生视图共用折叠上下文。
折叠提示前景层属于各列 `NSClipView` 的可视正文，而不是整个 `NSScrollView` 的顶层；
它盖住被折叠源码的字形，但不能盖住原生纵向／横向滚动条。
滚动、调整窗口尺寸或改变滚动条样式时，前景层必须跟随剪裁视口。
原生文本表面关闭自身不透明背景绘制，由下层 Diff 装饰视图统一绘制主题背景、
词级强调、占位斜纹与编辑态删除文字；否则系统默认文本背景会遮住差异强调。
只读差异的语法颜色属于派生富文本：不得对已安装的文本设置 `NSTextView.textColor`，
因为系统会将整篇逐词颜色改为单一颜色；工作区编辑器由原生语法插件管理颜色。
只读统一／分栏和工作区编辑均须检查亮暗外观下的最终像素。
这里不使用 WebKit 或 PierreDiffsSwift；浏览器仍使用 WebKit，两者不要混淆。


### 原始坐标与删除占位

按 LF 码点分行，CRLF 的 CR 留在原行文本中，不把 CRLF 当作不可拆的 Swift Character；
源范围始终使用各侧原始 UTF-16 坐标。只读 Diff 的派生文档为 TextKit 行布局补齐最后一个 LF，
原始内容及末行无换行标记不变；裸 CR／Unicode 分隔符导致原生段落数更多时，不用 Git 行数裁剪文本高度；
编辑态行号仅在真正 LF 后递增；同一 Git 行的多段 TextKit 视觉片段都获得对应背景和强调；
长删除块按当前视口直接绘制，不能依赖不在视野中的正文锚点；
延续片段不重复行号／起始删除 ghost，末尾删除 ghost 与缺少换行标记只归真实行尾，
不以当前视口边界冒充文件末尾。删除行占位按实际段落首尾定位，正文全部删除后仍可滚动查看被删行。
换行类型随文本变更更新，滚动绘制不再重复扫描全文。编辑、保存和重载仍保持原字节。
首个可编辑段落之前的删除行必须拥有实际可滚动的原生空位：TextKit 不计算首段的
`paragraphSpacingBefore`，因此首行删除占位使用文本容器顶部间距，
正文行号、背景、删除行绘制与滚动坐标必须同步采用这一偏移，避免两层文字重叠。
字号变化要重新计算占位高度；在文件末尾 LF 后插入内容属于新的 Git 行，
不得因此丢掉先前的首行或其它删除标记。上述占位不改动真实编辑缓冲的任何字节。

Diff 与文件编辑共享 NSTextStorage 的 Undo 通知和只读辅助功能写保护；
编辑态 Diff 还通过原生 `NSTextViewDelegate` 把自有 UndoManager 交给 AppKit。
`WorkspaceGitUITests` 通过独立完整 Bailey Dev 检查 Split／Unified 切换、
键盘编辑、⌘Z、⌘⇧Z 与 ⌘S，并核对实际工作区原文字节。
原生缓冲的 Undo／Redo 由 `NativeDiffTabTests` 检查；
直接调用 UndoManager 的宿主结果不能代替 Diff 完整 App 的撤销／重做快捷键验收。
核验入口见 [依赖维护](../dependencies.md#依赖与本地补丁)。

## 折叠与滚动

较长的未修改上下文默认折叠；点击 `xx unmodified lines` 标记才逐步展开，普通点击、光标移动或输入不自动展开。

两侧水平与垂直联动，短侧不能把长侧拉回；
行宽达到用户设置的最大显示宽度后，两侧可以具有相同滚动终点，即使源码行长不同；
内容显示方式不创建第二套工作区分屏。首次打开长文件应在原生布局就绪后定位首个变化，
不能被初始化期间的滚动同步拉回顶部。
原生正文、折叠区间和删除占位必须在首次展示时形成完整滚动范围；
TextKit 的预估布局不可导致滚到底后继续增长内容、缩短滑块或遮蔽最后一行。
布局只随内容、折叠范围、字号和换行宽度变化而重新测量，不在滚动事件中反复完整布局。
普通 LF／CRLF 的固定行高原生片段直接使用现有 Git UTF-16 行索引、折叠区间和删除行坐标，
同时决定可见行与完整滚动范围；不以首帧全文 `ensureLayout` 消除估计高度差。
滚动时仅在视口真正变化后重新排布当前视口；折叠范围内的隐藏原生段落
均投影到折叠提示行，使行坐标始终单调，避免远跳定位到不可见段落。
程序化或用户拖动滚动条时，先反映剪裁区的滚动状态，再计算 TextKit 视口；
不在滚动回调中强制整棵滚动视图同步布局来掩盖首帧错位。
首次从文件顶部直接拖到远处时，同一原生布局所有者先实现目标段落再更新视口，
不能依赖先用行跳转预热才能看见正文。
目标段落的 UTF-16 偏移必须取自实时可编辑文本行索引，不得复用可能滞后的 Diff 快照偏移；
LF／CRLF 原文直接复用已装载的原生段落索引，不在首次展示时重新扫描全文；
含裸 CR 或 Unicode 段落分隔符时，才独立建立符合 Git-LF 语义的行索引。
两种行坐标都从同一份原生正文取得，后续编辑分别增量更新，不增加第二份正文。
折叠展示版本变化不能用旧快照重建实时索引；末尾 LF 所带的原生空段落不计作 Git 源行。
仅布局该段落，不因滚动条远跳重新同步布局全文。
折叠中的隐藏段落由同一 TextKit 内容存储在元素枚举时直接跨越整个 UTF-16 区间，
不逐个访问被隐藏的原生段落；正向、反向及从隐藏区间内部开始的查找使用同一映射。
原文仍完整保存在唯一 `NSTextStorage`，Undo、选区和保存不依赖另一份精简正文。
手动改变折叠范围时，由同一 `NSTextStorage` 通知受影响后缀的布局失效，
不能只改显示行数而让 TextKit 保留旧段落范围。
原生固定高度在折叠展开后及视口重排期间必须重新约束 `NSTextView` 的实际高度，
避免 AppKit 重新布局覆盖已计算的完整滚动范围。
裸 CR、Unicode 段落分隔符可以让一个 Git LF 行包含多个视觉行；
尤其 U+2028 在 TextKit 中可能仍是同一个自然段落，固定布局片段必须覆盖其全部真实字形行，
而不是只按一个自然段落分配高度。
不折行且没有额外删除行间距时，使用现有原生段落索引与真实固定行高计算完整滚动范围，
不把自然段落数误作 Git 行数，也不强制布局全文；段落增删或 Undo 后实时更新。
非 LF 分隔符是否存在由唯一原生段落索引增量维护分隔符种类判断，
不能依赖尚未刷新到新版本的 Git-LF 行数或保留旧的独立布尔标志。
编辑回调同时传播段落数量和分隔符种类变化；CRLF 改成裸 CR 即使行数不变也须使布局失效，
不能逐键全文扫描。
选择「完整显示」且实际超出原生宽度时，仅对超宽自然段落用 TextKit 测量折行数，
将真实视觉行数累计到完整滚动范围；其余自然段落使用原生固定行高。
删除 Ghost 始终通过同一原生行坐标预留虚拟空间，不改写正文段落间距或 Undo 属性；
首行、正文中间和文件末尾的 Ghost 均须与字形、行号及滚动范围对齐。
固定行片段以当前原生段落位置计算行号及 Ghost 占位，不缓存旧 UTF-16 偏移；
删除占位须计入 TextKit 片段高度，防止行内编辑后叠字和视口漏绘。
验收核对行内编辑、折叠及删除块的实际字形像素，不仅检查背景颜色。
历史提交的纯原文预览不含 Diff 行装饰，仍须使用同一原生索引和固定行高快速路径；
不得因装饰数组为空而强制布局全文，深处行定位与真实滚动范围必须一致。
结构性编辑仅替换受影响的行装饰；工作区逐词强调保留行内相对位置，
绘制时由实时 Git-LF 行索引映射为原文 UTF-16 坐标，不复用过期快照。
整篇正文被新来源替换时，旧折叠、删除行占位、行装饰和展示版本同步退役，
即使新文件的展示序号与旧文件相同，也必须接纳新文件的第一次展示。

文本宽度、折行和横滚遵循[原生文本布局](editor.md#原生文本布局)。
「完整显示」在分栏仍按 24,576 点单行截断，以保留左右 Git 行对应；切换统一视图可查看完整内容。
设置立即生效，段落折行不得破坏删除行占位和分栏对齐。
只读 Diff 切换到不同正文时横向滚动回到开头，避免只剩长删除行末尾而较短新增行看似空白；
同一正文的主题／字体重绘及折叠展开保持既有横向位置。
替换只读正文后须先在同一 TextKit 布局所有者中落实保存的阅读锚点段落，
再恢复滚动位置并刷新视口；仅恢复原来的滚动 Y 不能保证新正文的目标字形已生成。
阅读锚点须按实际自然段落及已测折行数换算，不能沿用固定「Git 行号 × 行高」定位；
长行折行、裸 CR 等非 LF 段落均在此范围内。
折叠提示的辅助功能按钮使用与屏幕一致的坐标：原生行号栏是翻转的绘制坐标，
不得直接把文字的顶部 Y 坐标当作按钮的无障碍父视图 Y 坐标。
折叠标记仅占用隐藏 Git 行的首个原生段落，裸 CR 等分隔符生成的后续段落也必须隐藏。
行号栏、背景、折叠按钮和编辑器使用原文件 UTF-16 行起点映射，避免跳过隐藏段落后误算可见行号。
原生布局片段的字符范围用于识别文末虚拟空行：不能用整段富文本长度判断。

## 查找与焦点

Git／Files 的浏览可以显示 Diff 而不激活另一个可见组；
Diff 内部选区、两侧编辑焦点与窗口级交接分别维护。

查找使用当前原生文本视图：工作区、暂存区及历史 Diff 共用[查找浮层](find.md)。
Split 仅在当前聚焦的可见列查找，查找框获得焦点后仍使用该列；
替换只作用于可写工作区正文，切换布局时关闭已隐藏列的查找栏。

## 编辑与生命周期

过期请求和不同机器结果都不能生效，符号链接不作为普通文件写入。
原生 Worktree 编辑只以当前 TextKit 存储为可写真源：
Git 快照首次装入不计作用户编辑，普通输入只传修改范围和替换文字，
不在每键读取全文、同步复制另一个可写缓冲或对保存基线逐字节全量比较。
已知修改由 UTF-16 增减差异判脏；撤销一条来自干净状态的修改可直接恢复干净。
差异无法证明相同、缺失前置通知及 Unicode 规范等价时通过与 Files 共用的有界
UTF-16 分块逐单元比较验证文本精确相同，不在主线程为每次 Undo／IME 重建全文字符频数字典；
不以 Swift String 的规范等价或字符频数相等冒充原始字节相同。
只有 Diff 后台防抖结束或真正保存时才从原生缓冲取得完整一致快照；
旧任务仍依赖版本检查，保存期间的新编辑不得被旧快照标记干净。
多个失焦／手动保存请求由同一个任务串行合并，明确的编码选择按次执行；
真正写盘之后更新原始字节版本，失败时不清除编辑器和原生 Undo。
展示投影、手动展开及编辑装饰的后台计算属于发起任务的结构化子任务；
行级 Diff 在比较、Myers 和 Patience 过程中响应取消，只返回完整结果，
父任务取消后不得继续生成后续投影或发布过期结果。

`Project` 在标签／项目真实关闭时退役 `DiffTab` 拥有的唯一 `DiffNativeSurface`。
原生清理遵循[文本退役](editor.md#文档退役)，关闭和编码转换错误遵循[文件保存](file-saving.md#保存与关闭)。
SwiftUI 临时 `dismantleNSView`、切换 Dock 与调整窗口只撤销临时焦点，不清除正文或 Undo。

## 保存与失败

自动保存、条件写入与失败保稿遵循[文件保存](file-saving.md)，断线只读与重连遵循 [SSH](ssh.md)。
不能为恢复显示重建内容或改写其它路径。

输入、保存、断线、关闭标签或更换连接使读取失效时，`DiffTab` 取消其拥有的完整加载任务；
取消沿结构化 Git 子任务、工作区／SSH 运行器传到实际进程退出，不能只丢弃旧结果仍让远端继续执行。
旧读取不能清除后来请求的加载状态；被取消的单条 SSH 命令不能误判整条复用连接已断开。
进程取消、输入输出及超时规则遵循[架构](../architecture.md#分层)。
撤销回干净内容后仍可重新选择并刷新，不会因遗留 loading 永久卡住。

历史 Git 操作后允许重读没有未保存改动的工作区 Diff，并更新同一原生表面的文本；
通常导航可刷新干净文件，未保存编辑阻止旧读取覆盖正文。
已成功加载的不可变历史标签再次打开时复用原文，不重新查询 Git；live 文件重新选择时继续检查外部变化。

## 验证

授权 Windows SSH 回归还核对 Split 失焦保存的原始 Unicode 字节；数据读取专项见 [Diff 数据来源](diff-content.md)。

`DiffEngineTests` 验证行／词差异及字节坐标；
`NativeDiffTabTests` 与 `NativeGitHistoryFileTests` 使用真实临时 Git 仓库和原生 TextKit，
覆盖 Git 规范化／过滤器、布局、保存、只读来源、失败与恢复。
`WorkspaceGitUITests` 验证 Git Changes／Graph 打开、实际键盘输入、跨界面焦点及最终文件字节。
折叠提示的原生组件测试还要覆盖只读／编辑、亮暗主题、两种滚动条样式、双轴滚动及尺寸变化，
验证绘制层位于正文之上、滚动条之下，并保持点击和无障碍展开。
更改虚拟删除行绘制后，除首屏外必须在深处滚动的多个删除块之间验证可见像素；
只检查靠近正文锚点的一块会漏掉视口定位错误。
测试入口、适用环境和完成标准归 [testing.md](../testing.md)。

Git Review 还须验证已应用语法色在主题／字体变更时不被清除、长短行正文更新后的横向位置、
保留横滚的折叠展开，以及长行折行与 CRLF／Unicode 段落混合时的纵向锚点；
折叠上下文必须出现在真实窗口上缘，且对应的辅助功能按钮位置也必须一致；
不能仅凭 TextView 的辅助功能全文证明已绘制。
