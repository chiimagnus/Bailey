# 差异查看与编辑

Diff 使用原生 STTextView/TextKit 显示统一或分栏差异。本页负责数据读取、渲染、编辑和重挂载；相关行为或底层文本依赖改变时更新。

## Invariants

- **工作区、暂存区和历史分开读取。** 只有可编辑的工作区文本可以保存；保存不等于暂存或提交。
- **先判断原始字节。** 任一侧超过 5 MiB、包含二进制或不能解码为 UTF-8 时不提供文本 Diff；不能先丢掉 NUL 或无效字节再判断。
- **原生表面属于 `DiffTab`。** 切换项目或重挂载不得丢失编辑、撤销和滚动。
- **编辑后旧读取不得替换缓冲。** 过期请求和不同机器结果都不能生效，符号链接不作为普通文件写入。
- **分栏滚动尊重各自边界。** 两侧水平与垂直联动，短侧不能把长侧拉回；内容显示方式不创建第二套工作区分屏。

## 原生渲染

`DiffEngine` 计算行级及行内差异，`DiffSyntaxHighlighter` 使用编辑器同一语法与主题，原生视图绘制行号、增删标记和折叠上下文。这里不使用 WebKit 或 PierreDiffsSwift；浏览器仍使用 WebKit，两者不要混淆。

文本尺寸、固定行高和只读替换时的滚动是实际依赖契约。升级 STTextView 时，同时检查编辑器本身和 Diff 的补丁行为，见 [development.md](../development.md#依赖与本地补丁)。

## 保存与失败

工作区 Diff 的编辑、自动保存和原生缓冲保护遵守 [editor.md](editor.md)。保存失败保留内容及错误；断线只读、重连绑定及旧结果失效遵守 [ssh.md](ssh.md)。不能为恢复显示重建一份内容或改写其他路径。

## 验证

`DiffTabTests` 检查真实文本显示、统一／分栏、行内差异、编辑、撤销、保存与重新挂载。覆盖未跟踪、暂存、历史、字节与大小边界、两侧内容宽度不同、快速切换及在途读取。

还需在完整工作区中验证文件→Diff→文件的内容身份和焦点。接口返回或桥接成功不代表用户可用；性能测量须包含 TextKit 首屏、滚动和编辑，而不是 WebKit 指标。入口见 [testing.md](../testing.md)。
