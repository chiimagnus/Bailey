# 文件编辑器

本页维护读取、文本缓冲、保存、重载和高亮的契约。修改这些路径或原生编辑器集成时同步更新；树与文件操作见 [files.md](files.md)。

## Invariants

- **编辑内容属于长生命周期标签。** 文本、保存基线、原生编辑器、撤销栈、光标和滚动不能由临时 View 持有。
- **A 与 B 标签身份不同。** 同一停靠位置切换内容时按标签 ID 区分视图；切回或拖动后复用各自原有编辑器。
- **未保存状态来自原始字节比较。** 当前文本与保存基线字节相同才不再是脏内容；Unicode 规范等价但编码不同仍需保存，撤销回原字节必须清除标记。
- **保存失败保留编辑。** 不清空缓冲、不换机器、不关闭窗口、不结束终端。
- **旧读取不能覆盖新编辑。** 只有干净文件可重载，回写还要核对目标、请求代次和当前编辑状态。

## 读取与原生内容

可编辑文本须为 UTF-8 且不超过 5 MiB；图片走预览路径。超限、解码失败和读取失败分别给出可理解的结果，容量限制不是性能保证。

标签创建和会话恢复只建立身份；首次显示或非视图消费者等待文本时才共用一次初读。窗口重新激活不取消正在进行的初读；只有所属窗口成为主窗口才检查外部变化，同一文件在途刷新时合并重复焦点事件，完成后最多补读一次，后续磁盘变动仍可见。其他窗口不会被连带读取。SSH 断线重连只自动恢复已请求过的读取，从未消费的恢复标签仍保持懒加载。此前不可用的同一文件被重新创建后，新的文本请求可重新读取，不被旧失败状态锁死。文本读取有 5 MiB 上限，IO 与 UTF-8 解码在后台完成；图片仍完整读取并在原生侧建立预览，无效图片回到文本／容量规则。初读期间重命名会继续读取新路径，过期任务不能清除新读取的句柄。

Git Ignore 等非视图追加动作在文本缓冲干净时先读取磁盘当前内容；刷新失败即停止追加和保存，避免用过期缓存覆盖外部修改，原有草稿保留。尚未加载的文件与在途读取继续复用同一读取，真正的重载替换读取任务时等待者跟随同目标新任务；机器、连接或路径改变仍拒绝操作。

干净文件刷新失败且原文已加载时继续显示原文与原生编辑器，并标明上次加载的内容；在成功刷新前临时只读，不能把旧版本写回磁盘，仍可选择、复制和查找；文件确实不存在、超限或变成二进制时仍按对应不可用状态处理。成功重读后清除提示，脏编辑或断线使旧读取和待补读失效。只有磁盘内容确实改变时才替换原生文档；旧编辑器的回调不能改写新标签内容。字节、UTF-16 与行列坐标要一致，包含中文、emoji 和 CRLF。

查找或选择远处文字时，目标必须真正进入可见区域，前进和后退都不能误跳到文末。定位不改变正文或固定行高，也不以缩短整个文档来强制滚动。

## 保存与关闭

自动保存由编辑器失焦、工作标签／项目切换、窗口失焦等事件触发；文件内容不设保存定时器。⌘S 仍可用，读取当前聚焦内容的保存资格。

后台和手动写入按发起顺序串行。每次保存使用发起时的机器与内容；期间新增编辑不能被早先写入覆盖，早先成功也不能清除后续编辑的未保存标记。错误与原生编辑缓冲必须保留。

历史 Git 操作等待相应仓库的保存完成，不使用会关闭标签的保存路径。文件版本恢复还核对打开确认时该路径的 index 和工作区内容；取消或发现内容已变更时不得覆写。历史原文使用原生只读 TextKit，不能因共享编辑设置变成可写；只有真正的工作区文本属于文件编辑缓冲。保存失败或等待期间再次编辑时停止 Git；操作结束只重载干净缓冲。Git 操作的选项与目标检查由 [git.md](git.md#历史提交操作) 维护。

本机保存范围使用系统标准化路径比较，`/private/var` 与 `/var` 的同一文件不会漏过保护；远端路径不交给 Mac 的文件系统解析。其他仓库的未保存文本不随本次 Git 动作保存。

关闭文件先等待保存；失败时保留「保存／不保存／取消」确认，取消或写入失败不能丢弃编辑。关闭项目、单独窗口和应用退出同样等待保存；窗口保护复用现有保存路径，并让原生关闭通知继续到达 SwiftUI。

远端断线、重连与保存结果失效规则见 [ssh.md](ssh.md)。重新启动只重新读取磁盘，不承诺恢复未保存文本，见 [session-restore.md](session-restore.md)。

## 高亮与编辑

沿用 STTextView/TextKit 和现有增量解析。TSX 使用独立解析器，Markdown／HTML 保留嵌入语言；未知语法显示纯文本。文件扩展名变更时，在同一个编辑器上切换语法并清除旧色，不丢未保存内容和撤销历史。Markdown 是源码编辑，不承诺排版预览。

高亮只添加／清除临时前景色，不写入正文属性或重复设置字体；不能修改文本、污染撤销或更改用户字体。实际换字体仍由原生编辑器应用。第三方补丁与升级验证由 [development.md](../development.md#依赖与本地补丁) 维护，性能测量见 [testing.md](../testing.md#性能与内存测量)。

首次解析按空文档插入全文通知解析器。Tree-sitter 的行只按 LF 递增，列按 UTF-16 字节计数；不能使用 TextKit 的段落／字符列代替。CRLF、裸 CR、Unicode 段分隔符和代理对保留原字节，非法位置不伪装成文首。

坐标按当前正文的 LF 行起点索引查询；编辑时更新受影响行和后续偏移，不再每次从文首扫描。索引只保存行起点，不另存一份正文。

非空编辑沿用 Neon 的串行后台解析，不让小修改在主线程同步解析整棵语法树；正文快照保持稳定，当前视口在解析完成后更新颜色。文本布局等原生输入成本仍需单独测量。

每次编辑同时更新解析器和高亮器的范围。普通高亮与嵌入语言合并只交付同一编辑版本；过期成功和失败都丢弃，由当前版本重新请求，不能把旧范围标成已完成。

同一语言、同一种查询的首次编译由编辑器、嵌入片段与 Diff 共用，关闭一个等待者不取消其他消费者。内置查询没有热更新入口；编译失败在本进程内记住，保留纯文本或根语言着色，不通过反复重画触发重编译。

嵌入区域在后台解析和查询，同一编辑版本内共用片段结果；编辑时取消并清理旧结果，根语言与片段仍按同一版本交付。两者只更新本次请求的区间，不把尚未着色的整块区域提前标为有效。关闭编辑器后释放其独占的片段工作与结果。

围栏语言或标签变化可能改变整个片段的着色，但根语法树只报告局部变化。嵌入文档收到新根树时清除旧版本的有效标记，仍只请求当前视口；普通单语言文档继续使用局部失效范围。

后台解析返回的失效位置还须经过后续排队编辑的范围变换，不能让当前视口保留已经过时的有效样式。第三方运行时补丁归 [开发文档](../development.md#neon)。

组合输入结束标记时保留正文并清除临时样式；输入法交付最终文本时才替换组合范围。默认范围和显式替换使用同一正文坐标，不能把已删除的组合长度再用于删除后续文字。直接确认与替换已有内容只生成一次可撤销编辑，撤销恢复输入前的原文，重做恢复最终输入。

Git Ignore 在普通 `.gitignore` 标签的原生缓冲末尾插入规则，不重建编辑器；已有未保存文本一同串行保存，撤销仍可移除此次插入。追加与显示共用标签的按需读取，不能把加载中的空文本当作文件内容；失败保留缓冲和未保存状态。

## 验证

`FileTabTests` 覆盖读取、编辑、保存及原生行为；`SyntaxHighlightingTests` 检查真实解析器坐标、Unicode 分块字节、渲染色及字体／撤销不变；`EditorTextInputTests` 对照系统 NSTextView 验证组合输入结束、最终替换及撤销。工作区 UI 测试覆盖完整 `ContentView` 中的标签身份、多窗口和关闭。检查真实文件字节、原生文本、撤销和滚动，不只断言 ViewModel 字段。

覆盖写入期间编辑、保存失败、重命名、干净／脏文件重载、大小和编码边界、中文／emoji／CRLF、嵌入语言、A→B→A 与关闭失败。具体运行及人工验收范围见 [testing.md](../testing.md)。
