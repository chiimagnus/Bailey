# 文件树与文件操作

Files、Git 工作区、暂存区和提交历史共用同一套树语义。本页负责共享树及创建、重命名、删除；相关行为改变时同步更新。

## Invariants

- **一份树模型、一套行组件。** 不为 Files 或某个 Git 区域分别实现目录压缩、状态与交互。
- **目录压缩保留真实末级路径。** 展开、重命名和创建都操作显示所代表的目录，不操作错误的父级。
- **高亮范围就是点击范围。** 缩进、上下边缘和留白可点击；右侧按钮只执行自己的动作。
- **只滚动超出可用宽度的名称，动作不滚走。** 短名称不发生水平回弹；长名称可独立左右滚动。此规则适用于 Files、Git 暂存/未暂存及历史文件，列表保持懒加载，悬停、键盘、状态颜色及无障碍一致。
- **创建和重命名不能覆盖同名项，包括失效符号链接与同 inode 的不同硬链接。** 远端移动必须拒绝操作期间出现的普通目标文件；大小写改名不能仅凭 inode 相同就允许覆盖，失败或正常终止信号应恢复原路径。

## 共享呈现

`TreeDisplayModel` 负责显示结构，`TreeRowStyle` 及共享树行负责外观与命中。目录展开按工作范围保留；点击文件夹立即更新展开图标和无障碍状态，远端内容随后加载；首次显示时目录压缩需要探测的同层文件夹一起批量读取，不逐个等待 SSH。已读目录按机器、连接及根路径缓存，重复展开不重复查询；刷新合批读取已显示目录，失败保留原内容，创建、删除和重命名使对应目录缓存失效。状态通过名称颜色、提示和辅助功能表达，不另设字母状态列。Git 快照变化时沿父目录聚合最高优先级状态；查询时不再扫描全部文件。文件自身状态优先于忽略规则，忽略目录的子项继续继承忽略状态；Git 已删除路径即使磁盘上不存在，仍可准确识别。视觉唯一来源见 [ui.md](../ui.md#共享树行)。

## 文件操作

文件菜单、命令面板和标签栏「＋」使用同一创建路径：新建文件 ⌘N，新建文件夹 ⌥⌘N，默认目标为项目根目录；目录右键在相应目录创建。

异步操作核对发起时的项目、机器与路径。文件树读取中切换路径、机器或后端连接，新范围立即开始遍历，旧连接结果不能阻塞或覆盖新树；同时清除旧连接的文件行与输入草稿，创建或重命名不能在换连接后继续写旧目标。同一范围的重复刷新合并；当前连接暂时读取失败时保留已有列表，而非伪装成空目录。失败应显示原因，不能回退到本机、覆盖其他内容或打开另一项目中的文件。后端必须承担实际创建的排他性，UI 预检查不是数据保护。

历史 Git 文件右键沿用共用树行，提供查看历史版本、对当前工作区比较、真实 Git 恢复和路径复制；这不会改变普通 Files 树的双击、悬停或滚动行为。历史路径不存在时仅按确认的 Git 重命名关系打开当前文件，不能误打开同名但不同机器的文件。

重命名同步更新已打开文件的路径，后续保存写入新路径。SSH 大小写更名可能使用同目录临时项，常规失败会回滚；机器断电或强制终止无法保证回滚，异常残留的 `.bailey-rename.*` 不自动删除。删除本机内容与删除远端内容的恢复能力不同；远端不进入本机废纸篓，确认和数据保护见 [SECURITY.md](../../SECURITY.md)。

共享文件夹行允许像文件行一样在右侧显示独立操作按钮；Git 未提交树按分组使用此入口，Files 树和历史 Git 目录不新增操作。目录右侧按钮与右键菜单批量处理当前显示的子文件，不影响目录外或搜索隐藏的路径；压缩目录仍以真实末级目录为目标。CHANGES 中的文件或目录可追加精确的 `.gitignore` 规则，使用普通编辑标签与保存路径，详见 [Git 文件菜单](git.md#未提交改动与文件菜单)。

## 验证

`FileTreeTests` 检查展开即时反馈、首次同层目录批量查询、按需复用、批量刷新、断线保留、目录创建、重命名、范围与失败；`SSHFileTreeLiveTests` 验证实际 Windows SSH 批量读取、失败隔离及文件树冷开／热展开／刷新时的 SSH 请求次数；`TreeRowHitTestingTests` 验证真实行命中。共享组件改变时同时验收 Files、Git 工作区、暂存区及历史树，包含窄面板、大字体、长名称、点击边缘、右侧动作、键盘和无障碍。

实现入口：[FileTreeModel.swift](../../Bailey/Files/FileTreeModel.swift)、[TreeDisplayModel.swift](../../Bailey/Shared/Tree/TreeDisplayModel.swift)、[TreeRowStyle.swift](../../Bailey/Shared/Tree/TreeRowStyle.swift)。运行方式见 [testing.md](../testing.md)。
