# 文件树与文件操作

Files、Git 工作区、暂存区和提交历史共用同一套树语义。本页负责文件树的显示、刷新与文件操作；
相关行为改变时同步更新。

## Invariants

- **一份树模型、一套行组件。** 不为 Files 或某个 Git 区域分别实现目录压缩、状态与交互。
- **展开 ≠ 选中 ≠ 悬停 ≠ 浏览／打开 ≠ 焦点。** 展开只更新目录可见性；
  Files 的 Focus 游标与 Selection 集合分离。活动编辑器变化会按 VS Code 默认 Auto Reveal
  自动定位并选择匹配文件，但不等于键盘焦点转给 Files；方向键只移动 Focus，
  不改写 Selection，也不更换当前展示文件；
  Hover 是短暂显示反馈；只有 Files 真正获得键盘输入时游标行才绘制细边框。
  明确打开动作可按既有单／双击语义交接焦点，不能靠展示变化隐式聚焦；本机与 SSH 同名路径不合并。
  Files 以单一游标和独立多选集合表示不同状态；Git Changes 与 Git Graph 各有自己的键盘游标。
- **Files 只跟随项目，不跟随终端 SSH。** 本机项目即使终端已进入 SSH，
  仍按本机目录提供 Finder 与本机文件操作；SSH 项目不把远端路径交给 Finder。
- **重新挂载不阻塞旧树的有效操作。** 文件树已匹配当前项目、机器、连接及后端时，
  Files 重新显示后可立即点击，无须等待下一次目录扫描；目标变化时拒绝旧行操作。
  新建文件和文件夹不得清除已同步的树目标。
- **紧凑文件夹各段都是独立目录。** 一行 `a / b / c` 可以逐段点击和右键，选中段决定新建、重命名、
  粘贴及拖放的真实目录；行整体仍展开或折叠末级；不提供手动切换为非紧凑目录的菜单。
- **高亮范围就是点击范围。** 缩进、上下边缘和留白可点击；右侧按钮只执行自己的动作。
- **只滚动超出可用宽度的名称，动作不滚走。** 短名称不发生水平回弹；长名称可独立左右滚动。
  此规则适用于 Files、Git 暂存/未暂存及历史文件，列表保持懒加载，悬停、键盘、状态颜色及无障碍一致。
- **创建和重命名不能覆盖同名项，包括失效符号链接与同 inode 的不同硬链接。**
  远端移动必须拒绝操作期间出现的普通目标文件；大小写改名不能仅凭 inode 相同就允许覆盖，
  失败或正常终止信号应恢复原路径。

## 共享呈现

`TreeDisplayModel` 负责显示结构，`TreeRowStyle` 及共享树行负责外观与命中。
Files、Git Changes、提交历史及 Worktree 共用压缩目录的分段悬停、命中和菜单呈现；
各自传递真实目录身份与动作，不从显示名称拆路径，也不为中间段制造不可见的行游标。
文件与文件夹的**整行已不再是 SwiftUI 打开按钮**，
保留原 `ScrollView + LazyVStack` 和滚动／右键／拖放；
文件单击在另外仍可见的编辑器组展示文件但保留 Files 活动组，双击进入编辑器，菜单「打开」仍明确聚焦。
目录展开只改变子项，点击目录时是否把输入交给 Files 由当前实际点击语义决定，
不能由“展开状态改变”这个通知自动触发；右侧独立动作不执行行点击。
Bailey 没有额外的临时预览标签生命周期。文件树有一个独立的键盘选中游标：单击行或切换到 Files 标签时，
键盘由 Files 的原生输入接收视图持有。切换标签优先恢复有效 Focus，
否则定位最近工作文件并同步选择；仍无工作文件时只聚焦第一条可见项，不制造 Selection。
目录尚未读取完成时待行出现后聚焦，不自动打开文件。仅前台窗口可主动取得键盘焦点；
改名、新建及命令面板的原生输入框优先，退出命令面板后才恢复当前活动文件树。
↑/↓ 在可见行间移动，←/→ 处理目录展开及父子层级，Space 浏览文件，Return 明确切入编辑器，
Home／End 移到首尾可见行，Page Up／Down 按当前视口和行高移动，首尾钳制；
这些导航只更新游标与锚点，不改变 Selection 或打开文件。视口与字号变化后分页步长随之更新。
Escape 清空 Selection 并撤销未完成的内部拖动，保留 Focus。只有 Files 所在组活动、窗口接受键盘时才显示一层主题色细描边，不叠加系统默认焦点环；
重命名和新建的输入框保持各自的原生输入焦点。
行内编辑一旦开始，树便停止处理导航，即使原生 field editor 尚未挂载；输入法组词不被树吞键。
切换根或 SSH 机器清空旧行游标，折叠目录时游标返回可见祖先；
改名成功后选中行跟随新路径（包括目录内子文件），退出改名／新建输入框后焦点交回仍可见的 Files 树。
⌘点击增减单项并更新锚点；Shift 点击替换锚点所在的连续选区，保留其它不相邻选区，
反向点击可收缩该区间。Shift+↑/↓ 按新游标是否已选来增减成员，不从锚点重建区间；
游标已在首尾时不改变 Selection。⌘A 选择当前可见行并清除锚点，Escape 也清除锚点；
修饰键点击不打开文件或折叠目录。Selection 在 Files 持有键盘输入时使用主题色底，
失焦后保留中性色底；Files 不再单独为当前展示文件绘制第二种常驻灰底。
活动 Dock 文件标签 A→B 时，只有属于当前项目及机器、在文件树中可定位的 B 会替换旧选择，
必要时展开父目录并滚动；不额外激活 Files，也不夺走编辑器的键盘输入。
非活动组的预览、右键和不匹配项目根／机器的文件不会伪造新的 Selection。
切换项目根或 SSH 机器身份会清空 Selection；同一 SSH 机器、同一根的连接代次更新
暂时保留最后可信的行、Focus 与 Selection，直到新列表读取成功再剔除消失的路径。
新连接尚未核验目录时，旧行只供查看，禁止复制、移动、删除、重命名和新建文件／文件夹；
成功读取新连接的目录后恢复写入。普通折叠和刷新剔除不可见行。
更换连接即撤销菜单目标和未完成拖动；可信 Selection 的保留不延长临时操作的有效期。
改名和移动统一重映射展开、游标、目录段、Selection 与 Anchor；删除或过滤后不会因再次显示而复活选择。
与 VS Code Explorer 一致，右键先将 Focus 定位到实际命中的文件／目录：
如果目标已在 Selection 内则保留整组选中；否则 Selection 变为唯一右键目标。
压缩目录按实际点击的目录段判断，不把同一行的末级目录误作父级目标。
右键不抢 Terminal／Editor 的原生键盘焦点，也不隐式打开文件或展开目录。
已选集合内的菜单动作操作整组，右键集合外 B 的菜单动作只操作 B；
旧选中 A 的 AX 与背景同时撤销，B 获得选中语义和菜单期轮廓；
同一 Files 树只显示一个右键目标描边，不叠加旧行的键盘游标边框。
菜单结束后清除临时目标，只有 Files 真正持有焦点时才恢复游标描边。
Files 持有键盘焦点时，原生 Edit 优先操作多选集合；只有单选或无选择时
才以 Focus 解析当前项目，遵循 VS Code Explorer 的 `getContext(true)` 规则。
Terminal／Editor 持有焦点时仍保留原生输入行为。
右键菜单展开时 ⌘C／⌘X 等使用当前菜单中已启用的原生动作和目标；
无论 Files 是否拥有键盘焦点，菜单提示都按这次可执行的动作显示。
菜单取消或动作结束后不再截获输入，右键本身不浏览文件或展开目录。
Git 树仍各自维护键盘游标。目录展开按工作范围保留；
点击文件夹立即更新展开图标和无障碍状态，远端内容随后加载。
全折叠的文件树首次仅读取根目录，恢复原有展开状态时只读取必要层级；
紧凑文件夹仅使用已知目录内容合并名称，不为判断能否压缩而预读未展开的子目录。
压缩名称中的各级路径独立命中、悬停、右键、复制、重命名和新建；空白区域仍作用于整行末级。
点击压缩行时再读取其真实末级目录，同一次展开所需的目录可批量查询。
已读目录按机器、连接及根路径缓存，重复展开不重复查询；刷新合批读取已缓存目录，失败保留原内容，
创建、删除和重命名使对应目录缓存失效。状态通过名称颜色、提示和辅助功能表达，不另设字母状态列。
Git 快照变化时沿父目录聚合最高优先级状态；查询时不再扫描全部文件。
文件自身状态优先于忽略规则，忽略目录的子项继续继承忽略状态；
Git 已删除路径即使磁盘上不存在，仍可准确识别。视觉唯一来源见 [ui.md](../ui.md#共享树行)。

## 文件可见性

Settings → File Manager 中的 `files.exclude` 只决定 **Files 树显示什么**，不会删除内容，
也不影响 Git 状态和 `⌘P` 的文件搜索。规则使用每行一个相对当前 Files 根目录的 Glob：
`*`、`?` 匹配单层名称，
独立
的 `**` 匹配零级或多级目录；没有 `/` 的规则作用于任意层级的文件名，目录命中后其子树隐藏。默认只有 `**/.git`；
设置为空列表会显示 `.git`，其它点文件和 `node_modules` 默认可见。
不支持绝对路径、`..`、字符集和花括号表达式；无效规则或写盘失败会显示错误并保持此前生效值。

Files 标题栏的「显示被排除的文件」只在当前树临时显示隐藏项，不写入配置；切换项目/根/连接后关闭。
工作文件标签右键「在文件管理器中显示」会在**相同机器的当前项目**中展开祖先、选中并滚动到文件；
必要时临时显示被排除的路径，但不更改设置，也不触碰编辑缓冲。
根外、失效、换连接或另一台机器的文件给出错误，不自动重选项目或机器；Finder 定位仅用于本机文件标签。
规则变化只重算当前缓存的可见行，已经读取过的目录在隐藏后再显示不会重复列举；
新显现且从未读取的层级仍遵循原有懒加载。

## 自动刷新

**本机 Files 使用 FSEvents 自动刷新，不再每 2 秒读取目录。** App 前台可见 Files 或已打开 ⌘P
的非空本机文件查询共享当前项目文件树的同一条监听；无用户消费时释放。

监听覆盖当前根及可见目录（含压缩目录链）的符号链接目标；
当项目根本身是符号链接时，额外观察其父目录中的重定向；
但 `/tmp`、`/var` 等顶层别名不会为此监听整个 `/`，这类链接自身改指向依靠再次显示或激活时的重读核验。

外部创建、删除、移动或原子替换只重新读取受影响的已缓存目录，纯文件内容修改不重复列举父目录；
树内容未变不重复发布。事件溢出、根变动或挂载变化会重新核验已加载的目录；
根级失同步通知还会使 ⌘P 的深层文件索引失效，而不强制展开子树。

关闭消费界面或 App 退到后台时释放订阅；再次显示、终端命令完成和 App 激活时主动核验，
补回暂停期间的变化。未展开且未缓存的深层目录在展开时才读取。
已读目录内容变化、未展开子树的结构事件、
`.gitignore` 规则及 Git index／引用元数据变化会使 `⌘P` 索引失效；
linked worktree 的 Git 元数据使用这条监听的附加路径，
普通文件内容修改和短暂的 `index.lock` 不重建文件名索引。

**Windows 固定 SSH Files 优先使用系统文件事件通知**：可见面板启动独立、临时的 SSH PTY，
PowerShell `FileSystemWatcher` 就绪且首次目录读取成功后，收到合并通知才重新读取真实 SSH 文件目录，
空闲时不反复查询。

面板隐藏、App 后台或切换目标时取消监听；监听不可用、断线、到期、路径失效、非 Windows/自动 SSH、
符号链接根和可见目录链接等不能可靠覆盖的情况，**保留原来的 2 秒轮询回退**。
同一项目中的多个 Files 面板复用一个订阅；不同窗口的独立项目目前分别订阅。
不占用原有 SSH master 或终端，也不安装远端 Server。SSH Git 仍每 5 秒刷新。

固定 SSH 重连时旧请求按连接代次失效，新查询不等待旧通道超时；
同机器同根的重连若首次读取失败，保留已显示的文件行与游标，但在新连接尚未成功读取目录前拒绝移动、
删除及重命名。切换机器／项目仍清除旧行；真正读到新目录后再更新列表。

## 文件操作

文件菜单、命令面板和标签栏「＋」共用新建文件 ⌘N、新建文件夹 ⌥⌘N：
Files 聚焦时在选中目录内创建，选中文件时在其父目录创建；
活动编辑器文件属于当前项目根目录时在其相邻目录创建；其它情况回退项目根目录。
目录右键始终在右键目标目录创建；菜单展开期间的 ⌘N／⌥⌘N 使用本次目录目标，
提示仅对应真实可执行的菜单动作。
「文件 → 打开文件…」（⌘O）和标签栏「＋ → 打开文件…」是**选择已有 Mac 文件并增加编辑标签**，
不创建文件／项目或改动 Files/Git 根；添加本机项目另用「添加项目」（⇧⌘A）。

**Finder → 本机文件管理器执行复制，不是打开编辑标签。** 放在目录行（含压缩目录的真实末级）时复制到该
目录；
放在文件行时复制到其父目录；放在树留白或根路径标题时复制到当前 Files 根目录。
可批量导入文件和文件夹，源内容不移动、不删除；普通与失效符号链接复制链接本身，不递归展开其目标，
设备文件与命名管道不导入；操作不会新建 FileTab 或切换项目。
复制由 `LocalWorkspaceBackend` 在目标同卷的系统临时替换目录中完成，
再用原生不可覆盖的原子重命名发布，目录复制失败不会留下不完整的目标文件夹。
目标已有同名文件／文件夹（包含失效软链接）、来源缺失、目录自复制、
权限错误等按项拒绝并以原窗口 Sheet 报告；
投放到指向项目外部的目录链接也明确提示原因、不写入外部目录；
指向项目内部的目录链接在校验后固定实际目录作为复制目标，避免异步执行时链接改指向别处。
合法项继续，成功后由 `FileTreeModel` 刷新可见目录。
切换项目、关闭窗口或 SSH/本机目标身份不符时不把操作转向其它根；
**SSH 文件树拒绝 Finder→Mac 文件复制，不偷偷上传或回退写 Mac**。
同一 Files 树中的文件行和多选文件可拖到目录行、文件行的父目录或树根／留白：
默认移动，按住 Option 复制。内部拖动使用仅限当前进程的私有数据并核对原窗口、项目、连接及有效选中，
不会降级成 Finder 导入或跨窗口传输；操作完成后复用与右键菜单一致的防覆盖、脏稿保护及失败反馈。
Finder 投放仍只复制。本机文件向 Finder 拖动保留公开 Mac `fileURL`；
SSH 文件仅允许当前树内的私有拖动，不伪装本机 URL。文件剪贴板同样不支持跨机器传输。

同机复制由 `WorkspaceBackend.copy(from:to:)` 完成。
本机 Finder 导入和内部复制共用目标同卷暂存及 `RENAME_EXCL` 原子发布，SSH 先制作私有副本，
再复用已有的防覆盖 `rename` 发布；失败不删除源文件，也不把远端路径解释成 Mac 文件。
它由 Files 的复制／移动操作复用，不是新的 Finder 上传入口。

Files 拥有实际键盘焦点时，系统 Edit 菜单的剪切／复制／粘贴／删除／全选操作于所选文件；
⌘C／⌘X／⌘V／⌘A 与 Delete（⌫）均通过原生菜单和第一响应者执行，
文件树不再自行解析这些快捷键；独立的向前删除键（⌦）仍保留为文件树输入。
本机删除移入废纸篓，SSH 确认后永久删除。
Files 右键仅在快捷键目标与所选文件或目录一致时显示剪切 ⌘X、复制 ⌘C、粘贴 ⌘V 和删除 ⌫；
新建文件／文件夹仅在当前目录与系统菜单目标一致时显示快捷键。所有提示均不额外注册按键。
输入框、编辑器和终端沿用原生文本或终端行为，Git 树不接收文件编辑命令。右键按 VS Code Explorer 的顺序显示创建／打开、
剪切与复制（文件夹另有粘贴）、复制绝对／相对项目根路径、重命名与删除；
不提供独立「移动到…」「制作副本」「cd Here」或展开紧凑目录的菜单。
文件剪贴板附带项目、连接和路径身份，不能粘贴到其他项目或已重连的远端；
剪切只记录来源，粘贴真正成功后才移动源，部分失败保留未移动项以便重试。
**复制后粘贴到来源所在目录会生成 `name copy.ext`，再次粘贴生成 `name copy 2.ext`**（文件夹同理）；
从其他目录复制遇到同名目标仍拒绝覆盖。
删除本机文件进废纸篓，远端永久删除须在发起窗口的 Sheet 明确确认，已不存在的远端路径也会报告失败。

异步操作核对发起时的项目、机器与路径。`Project.syncFiles` 通过调用者提供的当前选择判定同步目标；
解析前、根路径解析后及文件树同步回写后都重新核对，项目领域无需依赖整个窗口管理者。
文件树读取中切换路径、机器或后端连接，新范围立即开始遍历，旧连接结果不能阻塞或覆盖新树；
同时清除旧连接的文件行与输入草稿，创建或重命名不能在换连接后继续写旧目标。同一范围的重复刷新合并；
当前连接暂时读取失败时保留已有列表，而非伪装成空目录。
失败应显示原因，不能回退到本机、覆盖其他内容或打开另一项目中的文件。
后端必须承担实际创建的排他性，UI 预检查不是数据保护。批量同机文件操作先合并父子重叠选择，
逐项返回成功与失败；目标目录和来源的实际父目录均不能越过项目根；
验证后通过实际父目录操作，避免软链接在等待 IO 时改指向项目外。
新建与重命名采用同一边界，仍允许操作软链接条目本身。
成功移动会维护 Files 游标、目录展开和打开文件标签；切项目后已完成的磁盘结果仍交回原窗口所有者，
旧树不接受过期行。合法文件名的首尾空格原样保留。

历史 Git 文件右键沿用共用树行，提供查看历史版本、对当前工作区比较、真实 Git 恢复和路径复制；
这不会改变普通 Files 树的双击、悬停或滚动行为。
历史路径不存在时仅按确认的 Git 重命名关系打开当前文件，不能误打开同名但不同机器的文件。

移动、重命名和删除先在现有应用窗口登记表中找出受影响的文件及可写 Diff，等待其在途保存，
确认脏缓冲已写入后才修改磁盘；移动期间新触发的自动保存延后到路径更新后。
两个窗口若同时持有同一文件的不同脏稿，拒绝操作，避免静默覆盖。
实际修改完成后按机器身份更新各窗口的文件标签及固定项目路径；
本机通过不同符号路径打开的同一实体也会映射到实际新路径；
成功删除的干净标签关闭，删除期间新产生的脏稿保留为只读，不允许后续自动保存重建旧文件。
重命名同步更新已打开文件的路径，后续保存写入新路径。SSH 大小写更名可能使用同目录临时项，
常规失败会回滚；机器断电或强制终止无法保证回滚，异常残留的 `.bailey-rename.*` 不自动删除。
删除本机内容与删除远端内容的恢复能力不同；
远端不进入本机废纸篓，确认和数据保护见 [SECURITY.md](../../SECURITY.md)。

共享文件夹行允许像文件行一样在右侧显示独立操作按钮；
Git 未提交树按分组使用此入口，Files 树和历史 Git 目录不新增操作。
目录右侧按钮与右键菜单批量处理当前显示的子文件，不影响目录外或搜索隐藏的路径；
压缩目录仍以真实末级目录为目标。CHANGES 中的文件或目录可追加精确的 `.gitignore` 规则，
使用普通编辑标签与保存路径，详见 [Git 文件菜单](git.md#未提交改动与文件菜单)。

## 验证

`FileTreeTests` 检查展开即时反馈、首次仅根目录查询、逐层按需读取、缓存复用、批量刷新、断线保留、
目录创建、重命名、范围与失败；`PanelContextTests` 验证 Files 重新挂载时复用有效目标、
扫描未完成时仍可操作，以及批量关闭标签和新建文件不清除目标身份；
`SSHFileTreeLiveTests` 验证实际 Windows SSH 批量读取、
失败隔离及文件树冷开／热展开／刷新时的 SSH 请求次数；
`SharedTreeUITests` 在独立 Bailey Dev 验证真实 Files／Git 整行命中、右键不误预览、单击／双击、
窄宽横滚、右侧 Stage 操作和明暗主题焦点底色；
`WorkspaceFilesUITests` 检查连续 ⌘W 清空文件标签后从 Files 再打开的实际正文，以及真实方向键／Space、
修饰键多选、剪贴板和文件操作的最终结果；`FileTreeTests` 检查异步目录到达和过期目标；
`WorkspaceDockUITests` 验证工具切换后旧编辑器不再接收键盘；
`FileTreeTests` 覆盖真实复制字节、文件夹/子目录、中文、同名冲突、原子失败不留部分目录、
并发唯一发布、失效来源与目标符号链接、指向目标祖先的目录链接、特殊文件拒绝、超出根路径的禁放，
以及 POSIX 根目录 `/`、相似前缀目录和禁止目录递归自复制。
签名测试 App 的 Finder 实际拖放需要逐一检查目录行、文件行、根标题、留白、
复制后的磁盘文件和 Files 刷新、冲突 Sheet、项目及文件标签数量，不能拿 `.copy` 指针反馈当复制成功。
共享组件改变时同时验收 Files、Git 工作区、暂存区及历史树，包含窄面板、大字体、长名称、点击边缘、
右侧动作、键盘和无障碍。`GitChangesUITests` 从真实 App 操作文件夹的行尾按钮与右键菜单，
再核对 Git index 只修改选定目录，不以合成鼠标命中替代验收。
