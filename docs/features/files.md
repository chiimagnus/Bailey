# 文件树与文件操作

Files、Git 工作区、暂存区和提交历史共用同一套树语义。本页负责共享树及创建、重命名、删除；相关行为改变时同步更新。

## Invariants

- **一份树模型、一套行组件。** 不为 Files 或某个 Git 区域分别实现目录压缩、状态与交互。
- **目录压缩保留真实末级路径。** 展开、重命名和创建都操作显示所代表的目录，不操作错误的父级。
- **高亮范围就是点击范围。** 缩进、上下边缘和留白可点击；右侧按钮只执行自己的动作。
- **只滚动超出可用宽度的名称，动作不滚走。** 短名称不发生水平回弹；长名称可独立左右滚动。此规则适用于 Files、Git 暂存/未暂存及历史文件，列表保持懒加载，悬停、键盘、状态颜色及无障碍一致。
- **创建必须拒绝同名项，包括符号链接。** 不能只做创建前的存在检查，也不能覆盖用户文件。

## 共享呈现

`TreeDisplayModel` 负责显示结构，`TreeRowStyle` 及共享树行负责外观与命中。目录展开按工作范围保留；点击文件夹立即改变图标和无障碍展开状态，远程子项随后加载。已读取目录按项目、机器、连接与根路径缓存，重复展开不再重复 SSH 查询；刷新用一次远程批量读取更新已显示目录，失败保留原内容，不跨机器复用。目录创建、删除、重命名使相关缓存失效。状态通过名称颜色、提示和辅助功能表达，不另设字母状态列。视觉唯一来源见 [ui.md](../ui.md#共享树行)。

## 文件操作

文件菜单、命令面板和标签栏「＋」使用同一创建路径：新建文件 ⌘N，新建文件夹 ⌥⌘N，默认目标为项目根目录；目录右键在相应目录创建。

异步操作核对发起时的项目、机器与路径。失败应显示原因，不能回退到本机、覆盖其他内容或打开另一项目中的文件。后端必须承担实际创建的排他性，UI 预检查不是数据保护。

历史 Git 文件右键沿用共用树行，提供查看历史版本、对当前工作区比较、真实 Git 恢复和路径复制；这不会改变普通 Files 树的双击、悬停或滚动行为。历史路径不存在时仅按确认的 Git 重命名关系打开当前文件，不能误打开同名但不同机器的文件。

重命名同步更新已打开文件的路径，后续保存写入新路径。删除本机内容与删除远端内容的恢复能力不同；远端不进入本机废纸篓，确认和数据保护见 [SECURITY.md](../../SECURITY.md)。

共享文件夹行允许像文件行一样在右侧显示独立操作按钮；Git 未提交树按分组使用此入口，Files 树和历史 Git 目录不新增操作。目录右侧按钮与右键菜单批量处理当前显示的子文件，不影响目录外或搜索隐藏的路径；压缩目录仍以真实末级目录为目标。CHANGES 中的文件或目录可追加精确的 `.gitignore` 规则，使用普通编辑标签与保存路径，详见 [Git 文件菜单](git.md#未提交改动与文件菜单)。

## 验证

`FileTreeTests` 检查展开即时反馈、按需复用、批量刷新、断线保留、目录创建、重命名、范围与失败；`TreeRowHitTestingTests` 验证真实行命中。共享组件改变时同时验收 Files、Git 工作区、暂存区及历史树，包含窄面板、大字体、长名称、点击边缘、右侧动作、键盘和无障碍。

实现入口：[FileTreeModel.swift](../../kero/Files/FileTreeModel.swift)、[TreeDisplayModel.swift](../../kero/Shared/Tree/TreeDisplayModel.swift)、[TreeRowStyle.swift](../../kero/Shared/Tree/TreeRowStyle.swift)。运行方式见 [testing.md](../testing.md)。
