# 文件树与文件操作

Files、Git 工作区、暂存区和提交历史共用同一套树语义。本页负责文件树的显示、刷新与文件操作；相关行为改变时同步更新。

## Invariants

- **一份树模型、一套行组件。** 不为 Files 或某个 Git 区域分别实现目录压缩、状态与交互。
- **展开 ≠ 选中 ≠ 悬停 ≠ 浏览／打开 ≠ 焦点。** 展开只更新目录可见性；Files 保留自己的选中行游标，当前打开文件保持灰色背景，方向键移到其它行不改变已显示文件；Hover 是短暂显示反馈；只有 Files 真正获得键盘输入时游标行才绘制细边框。明确打开动作可按既有单／双击语义交接焦点，不能靠展示变化隐式聚焦；本机与 SSH 同名路径不合并。Files 以单一游标和独立多选集合表示不同状态；Git Changes 与 Git Graph 各有自己的键盘游标。
- **目录压缩保留真实末级路径。** 展开、重命名和创建都操作显示所代表的目录，不操作错误的父级。
- **高亮范围就是点击范围。** 缩进、上下边缘和留白可点击；右侧按钮只执行自己的动作。
- **只滚动超出可用宽度的名称，动作不滚走。** 短名称不发生水平回弹；长名称可独立左右滚动。此规则适用于 Files、Git 暂存/未暂存及历史文件，列表保持懒加载，悬停、键盘、状态颜色及无障碍一致。
- **创建和重命名不能覆盖同名项，包括失效符号链接与同 inode 的不同硬链接。** 远端移动必须拒绝操作期间出现的普通目标文件；大小写改名不能仅凭 inode 相同就允许覆盖，失败或正常终止信号应恢复原路径。

## 共享呈现

`TreeDisplayModel` 负责显示结构，`TreeRowStyle` 及共享树行负责外观与命中。文件与文件夹的**整行已不再是 SwiftUI 打开按钮**，保留原 `ScrollView + LazyVStack` 和滚动／右键／拖放；文件单击在另外仍可见的编辑器组展示文件但保留 Files 活动组，双击进入编辑器，菜单「打开」仍明确聚焦。目录展开只改变子项，点击目录时是否把输入交给 Files 由当前实际点击语义决定，不能由“展开状态改变”这个通知自动触发；右侧独立动作不执行行点击。Bailey 没有额外的临时预览标签生命周期。文件树有一个独立的键盘选中游标：单击行或切换到 Files 标签时，键盘由 Files 的原生输入接收视图持有。切换标签优先恢复已选中行，否则定位当前工作文件，再选第一条可见项；目录尚未读取完成时，待行出现后选中，不自动打开文件。仅前台窗口可主动取得键盘焦点；改名、新建及命令面板的原生输入框优先，退出命令面板后才恢复当前活动文件树。↑/↓ 在可见行间移动，←/→ 处理目录展开及父子层级，Space 浏览文件，Return 明确切入编辑器，Escape 清除选中。只有 Files 所在组活动、窗口接受键盘时才显示一层主题色细描边，不叠加系统默认焦点环；重命名和新建的输入框保持各自的原生输入焦点。切换根或 SSH 机器清空旧行游标，折叠目录时游标返回可见祖先；改名成功后选中行跟随新路径（包括目录内子文件），退出改名／新建输入框后焦点交回仍可见的 Files 树。⌘点击增减单项、Shift 点击或 Shift+↑/↓ 选择可见连续范围、⌘A 选择当前可见行；修饰键点击不打开文件或折叠目录。多选集合使用浅强调色底、当前工作文件继续保持独立灰底；切根、机器、连接时清空集合，折叠及刷新时剔除不可见行。右键已选中行保留集合，右键未选中行只针对该项，实际批量操作由 Issue #5 后续任务接入。Git 树仍各自维护键盘游标。目录展开按工作范围保留；点击文件夹立即更新展开图标和无障碍状态，远端内容随后加载；首次显示时目录压缩需要探测的同层文件夹一起批量读取，不逐个等待 SSH。已读目录按机器、连接及根路径缓存，重复展开不重复查询；刷新合批读取已显示目录，失败保留原内容，创建、删除和重命名使对应目录缓存失效。状态通过名称颜色、提示和辅助功能表达，不另设字母状态列。Git 快照变化时沿父目录聚合最高优先级状态；查询时不再扫描全部文件。文件自身状态优先于忽略规则，忽略目录的子项继续继承忽略状态；Git 已删除路径即使磁盘上不存在，仍可准确识别。视觉唯一来源见 [ui.md](../ui.md#共享树行)。

## 自动刷新

Files 面板在 App 前台显示时，本机与 SSH 都每 2 秒检查当前目录及已缓存目录；打开面板、切换项目、终端命令完成或 App 重新激活也会同步。内容不变时不重新发布文件行，读取失败时保留原有列表。**Files 尚未使用文件事件监听**，与已经采用 FSEvents 的本机 Git 不同。

## 文件操作

文件菜单、命令面板和标签栏「＋」使用同一创建路径：新建文件 ⌘N，新建文件夹 ⌥⌘N，默认目标为项目根目录；目录右键在相应目录创建。「文件 → 打开文件…」（⌘O）和标签栏「＋ → 打开文件…」是**选择已有 Mac 文件并增加编辑标签**，不创建文件／项目或改动 Files/Git 根；添加本机项目另用「添加文件夹」（⇧⌘A）。

**Finder → 本机文件管理器执行复制，不是打开编辑标签。** 放在目录行（含压缩目录的真实末级）时复制到该目录；放在文件行时复制到其父目录；放在树留白或根路径标题时复制到当前 Files 根目录。可批量导入文件和文件夹，源内容不移动、不删除；普通与失效符号链接复制链接本身，不递归展开其目标，设备文件与命名管道不导入；操作不会新建 FileTab 或切换项目。复制由 `LocalWorkspaceBackend` 在目标同卷的系统临时替换目录中完成，再用原生不可覆盖的原子重命名发布，目录复制失败不会留下不完整的目标文件夹。目标已有同名文件／文件夹（包含失效软链接）、来源缺失、目录自复制、权限错误等按项拒绝并以原窗口 Sheet 报告；投放到指向项目外部的目录链接也明确提示原因、不写入外部目录，合法项继续；成功后由 `FileTreeModel` 刷新可见目录。切换项目、关闭窗口或 SSH/本机目标身份不符时不把操作转向其它根；**SSH 文件树拒绝 Finder→Mac 文件复制，不偷偷上传或回退写 Mac**。批量文件操作、剪切／粘贴、内部树移动、覆盖确认及远端传输仍归 [Issue #5](https://github.com/chiimagnus/Bailey/issues/5) 的其余功能。文件树向外拖动时，仅本机条目提供 Mac `fileURL`；SSH 条目可通过「复制路径」获取原路径，不伪装本机 URL。

同机复制由 `WorkspaceBackend.copy(from:to:)` 完成。本机 Finder 导入和内部复制共用目标同卷暂存及 `RENAME_EXCL` 原子发布，SSH 先制作私有副本，再复用已有的防覆盖 `rename` 发布；失败不删除源文件，也不把远端路径解释成 Mac 文件。此后端能力由 File Manager 后续批量操作任务接入，不是新的 Finder 上传入口。

异步操作核对发起时的项目、机器与路径。`Project.syncFiles` 通过调用者提供的当前选择判定同步目标；解析前、根路径解析后及文件树同步回写后都重新核对，项目领域无需依赖整个窗口管理者。文件树读取中切换路径、机器或后端连接，新范围立即开始遍历，旧连接结果不能阻塞或覆盖新树；同时清除旧连接的文件行与输入草稿，创建或重命名不能在换连接后继续写旧目标。同一范围的重复刷新合并；当前连接暂时读取失败时保留已有列表，而非伪装成空目录。失败应显示原因，不能回退到本机、覆盖其他内容或打开另一项目中的文件。后端必须承担实际创建的排他性，UI 预检查不是数据保护。

历史 Git 文件右键沿用共用树行，提供查看历史版本、对当前工作区比较、真实 Git 恢复和路径复制；这不会改变普通 Files 树的双击、悬停或滚动行为。历史路径不存在时仅按确认的 Git 重命名关系打开当前文件，不能误打开同名但不同机器的文件。

重命名同步更新已打开文件的路径，后续保存写入新路径。SSH 大小写更名可能使用同目录临时项，常规失败会回滚；机器断电或强制终止无法保证回滚，异常残留的 `.bailey-rename.*` 不自动删除。删除本机内容与删除远端内容的恢复能力不同；远端不进入本机废纸篓，确认和数据保护见 [SECURITY.md](../../SECURITY.md)。

共享文件夹行允许像文件行一样在右侧显示独立操作按钮；Git 未提交树按分组使用此入口，Files 树和历史 Git 目录不新增操作。目录右侧按钮与右键菜单批量处理当前显示的子文件，不影响目录外或搜索隐藏的路径；压缩目录仍以真实末级目录为目标。CHANGES 中的文件或目录可追加精确的 `.gitignore` 规则，使用普通编辑标签与保存路径，详见 [Git 文件菜单](git.md#未提交改动与文件菜单)。

## 验证

`FileTreeTests` 检查展开即时反馈、首次同层目录批量查询、按需复用、批量刷新、断线保留、目录创建、重命名、范围与失败；`SSHFileTreeLiveTests` 验证实际 Windows SSH 批量读取、失败隔离及文件树冷开／热展开／刷新时的 SSH 请求次数；`SharedTreeUITests` 在独立 Bailey Dev 验证真实 Files／Git 整行命中、右键不误预览、单击／双击、窄宽横滚、右侧 Stage 操作和明暗主题焦点底色；`WorkspaceFilesUITests` 检查真实方向键／Space、修饰键多选不预览、改名与新建退出焦点；`FileTreeTests` 检查异步目录到达和过期目标；`WorkspaceDockUITests` 验证工具切换后旧编辑器不再接收键盘；`FileTreeTests` 覆盖真实复制字节、文件夹/子目录、中文、同名冲突、原子失败不留部分目录、并发唯一发布、失效来源与目标符号链接、指向目标祖先的目录链接、特殊文件拒绝、超出根路径的禁放，以及 POSIX 根目录 `/`、相似前缀目录和禁止目录递归自复制。签名测试 App 的 Finder 实际拖放需要逐一检查目录行、文件行、根标题、留白、复制后的磁盘文件和 Files 刷新、冲突 Sheet、项目及文件标签数量，不能拿 `.copy` 指针反馈当复制成功。共享组件改变时同时验收 Files、Git 工作区、暂存区及历史树，包含窄面板、大字体、长名称、点击边缘、右侧动作、键盘和无障碍。`GitChangesUITests` 从真实 App 操作文件夹的行尾按钮与右键菜单，再核对 Git index 只修改选定目录，不以合成鼠标命中替代验收。
