# HTML 静态预览

`.html`、`.htm` 默认打开源码。按 `⌘⇧V` 切换静态预览，文件标签右键可选择并排；
使用[文件查看路由](file-viewer.md)与同一原生文本缓冲。

## Invariants

- **静态预览与浏览器运行分开。** 系统 WebKit 只排版当前文档，预览不执行网页脚本或提交网络请求。
- **资源访问不越权。** 只允许原文件后端与范围内的资源，有界读取并验证位图；拒绝外部或越界请求。
- **只读展示实时正文。** 不以临时 HTML、自动保存或第二份 DOM 草稿代替编辑器；旧渲染结果不能覆盖新版本。

## 静态预览

预览直接使用当前正文（包括未保存的编辑），不另写临时 HTML。
快速连续修改合并为最新渲染请求，取消旧页面加载；同一文件的热更新保留阅读位置，不自动保存。
源码和预览分别使用[共享查找浮层](find.md)。

系统 WebKit 排版网页和 CSS，但不运行网页脚本、提交表单、打开其它页面或访问外部网络。
表单中的文本只能选取和复制，复选框、文件选择、下拉框等交互控件不可操作。
相对样式、图片和字体遵循[共享资源权限](file-viewer.md#预览资源权限)；
缺失或被拒绝的图片保留网页的替代文字，不影响查看或编辑源码。
单页位图（动画逐帧累计）最多接收 3,200 万像素；超出预算的图片不会送给 WebKit 解码，
正文和样式仍可阅读。
如果渲染进程退出，可以回到源码，再切回预览。正在加载的资源会取消，源码和保存状态不受影响。

## 在浏览器运行

本机 HTML 文件标签的右键可显式在正常浏览器中运行。存在草稿时可选择「打开已保存的 HTML」或「保存并在浏览器中打开」；
前者不触发该次导航的自动保存，后者仅在保存成功后运行。浏览器能运行脚本，静态预览仍不能。
浏览器读取范围及 SSH 限制见 [browser.md](browser.md#地址与导航)。

## 验证

`HTMLFilePreviewTests` 检查真实 WebKit 排版、编码、图片及外部请求隔离；`HTMLFilePreviewUITests`
检查系统菜单、源码、并排与磁盘原字节，`HTMLExplicitBrowserUITests` 检查显式运行及保存保护。
资源、条件保存及关闭的共用回归见[文件预览共用验收](../testing.md#文件预览共用验收)。
