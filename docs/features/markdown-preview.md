# Markdown 阅读预览

`.md`、`.markdown`、`.mdx` 默认打开源码；按 `⌘⇧V` 切换只读阅读预览，标签右键可选并排。
共用[文件查看路由](file-viewer.md)及[文本编辑器](editor.md)；阅读排版、链接和富内容规则归本页。

## Invariants

- **只读渲染，不执行文档代码。** 使用 SwiftUI 原生阅读器；MDX 不执行 JSX，HTML 不执行 JavaScript。
- **原文坐标是定位真源。** 渲染、选择、同步滚动与源码定位使用实际原文区间，不按显示文本猜测位置。
- **展示状态不改写源码。** 折叠、复制、链接导航及预览不会增加第二份正文或撤销栈。
- **资源按文件授权。** 不越界读取，不自动联网加载媒体，不发布旧版本资源或解析结果。

## 阅读与富内容

预览由 `swift-markdown` 解析 AST，Bailey 的 SwiftUI 组件直接渲染 GFM、YAML 元数据、
受限 HTML／SVG、Mermaid、本地音视频和 Canvas 原生公式；无效公式保留可选择的原文，
货币美元符及代码／链接不被当作公式；代码围栏复用 [Tree-sitter 高亮](syntax-highlighting.md)。
资源遵循[共享预览权限](file-viewer.md#预览资源权限)，内容不执行 WebKit 或 JavaScript。
SVG 共用[矢量解析与预算](svg-preview.md)，图片、GIF 与 Mermaid 放大使用[共享图形视口](image-preview.md#缩放与平移)。
内嵌 GIF 超过 32 帧或解码像素预算时显示静态封面；动画偏好见[图片](image-preview.md#gif-播放)。
音视频必须主动加载，范围、暂存与播放见[音视频](media-playback.md#markdown-嵌入媒体)。

阅读排版沿用 GitHub Primer 的标题、表格、引用、代码与响应式语义；
普通换行随正文自然折行，显式硬换行保留。顶层引用中，GitHub 的五种提示标记显示图标和标题，
并随深浅外观切换配色。宽表格只在表格内横向滚动，表头有独立的辅助功能语义。
预览背景、正文与链接沿用当前 Bailey 选中的终端主题。不论同段还是跨块拖选，
预览只绘制一份连续选区，使用该终端主题的选区底色和文字色，不叠加 macOS 的文字选色。
可选择的正文保持 I-beam；只有文字链接、图片、展开控件、标题锚点和复制按钮的实际交互区域使用手形指针。
从带格式的链接文字开始拖选时仍可跨段落连续选择，不触发链接跳转。
代码块不将最后一个行结束符渲染为额外空行；保留实际空行、缩进和复制按钮的原始代码内容。
代码复制在悬停／键盘聚焦时显示操作与成功反馈；页内与跨文件标题／脚注链接按解码片段定位，无效片段显示错误。

## 源码定位与滚动同步

预览解析按文件标签身份及编辑代次取消过期任务。
并排预览默认使用原始 UTF-16 源码区间进行双向滚动同步，可在文件标签右键菜单关闭。
跳到屏外内容时，预览按懒布局的行身份找到目标，再用实际字形或媒体矩形对齐；
不先构建沿途各行，也不会仅为滚动而移动源码光标。
源码区间按 Markdown 的换行规则计算（LF、CRLF 或 CR）；其他 Unicode 分隔符保留在原位置。
公式和脚注的解析替换保留原文字节区间，所以替换前后的列宽不同也不会影响源码定位。
预览的文字字形、Canvas 公式和 Markdown 图片共用原文偏移与实际视口坐标；
同段多条公式或图片可精确同步滚动，嵌套在强调文字中的图片仍作为原生媒体呈现。
在块前增删内容后重新解析或切换视图，仍可恢复原阅读位置。
滚动后，选择和双击仍以视口内实际文字为准。双击有原文坐标的预览文字可定位到源码；
并排时保留预览，链接仍按原来的动作导航。
转义符或字符实体渲染成单个符号时，双击定位到原文记法的起点。
块 HTML 的普通文字与实体也可定位到原文；相同文字重复出现时以实际选中的位置为准。

## 选择与复制

预览支持跨段落分组、标题、引用、列表、表格及代码块的连续拖选，
也可用 Shift 扩选或 ⌘A／⌘C 复制可见内容；代码围栏、隐藏元数据不进入剪贴板。
任务复选框与嵌套层级保留阅读语义，引用中的任务也显示只读状态，不改写源码。
块 HTML 可部分选择，Details 的复制内容遵从当前展开状态。

## 大纲与链接

文件标签右键的 **Outline…** 按标题层级打开导航大纲，方向键选择、Return 跳转、Escape 关闭。
预览标题悬停或键盘聚焦后可展开或折叠章节及其子章节；
折叠只改变展示，复制和全选不包含隐藏正文，编辑、Undo 或保存仍保留完整源文件。
在折叠章节中的页内链接目标会自动展开并定位。脚注定义末尾的 ↩ 可返回正文引用。

查找能力以[当前内容查找范围](find.md#操作)为准；尚未实施的能力留在现行 Feature 计划。
