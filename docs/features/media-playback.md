# 音视频播放

在本机打开音频或视频文件，使用 macOS 原生播放器。Markdown 可通过授权资源主动加载嵌入媒体。
本页维护格式验证、AVKit 控件及播放生命周期。

## Invariants

- **按实际解码轨道选择播放器。** 不凭后缀假定内容，不能将损坏视频误当作音频。
- **使用 AVFoundation／AVKit。** 独立播放不复制整份媒体，不另绘波形或控制条，不改写源文件。
- **播放属于原标签。** 切换、全屏和关闭有明确不同的生命周期，关闭释放原生播放器与临时资源。

## 格式与读取

本机音频、视频候选在文本读取之前交给 AVFoundation 检查。实际可解码轨道决定播放方式：
例如，只有音轨的 MP4 按音频打开；存在视频轨却无法解码时明确拒绝，不伪装成音频。
媒体直接从读得动的本机普通文件播放，不复制整份文件，也不进入正文或保存。
打开与重载以原路径的实际文件身份为准；发现同路径被替换时停止旧播放器。独立 SSH 媒体文件不支持播放，不以同名本机文件回退。
依赖其他文件的引用型 MOV 不支持播放；只有轨道索引或样本无法解码的损坏文件也会明确拒绝。
打开时验证首个真实解码的音频缓冲或视频帧，不为了判定格式预读整份媒体。请改用有效的自包含文件。

## 原生播放与生命周期

音频文件使用 macOS 的 AVKit 系统播放器，提供播放／暂停、进度、音量与静音；不另绘波形或自定义控制条。
独立和 Markdown 内嵌音视频统一允许系统对单声道、立体声及多声道音频进行空间化；实际效果由系统设置、音轨和输出设备决定。
在支持 APAC 解码的 macOS 上，可原生播放该格式，不引入额外解码器。
窄窗格保留原生播放控件；若部分控件被裁切且无法通过横向滚动访问，请扩大窗格。
播放器键盘输入归当前的原生控件，不给终端或编辑器增加全局快捷键。
切换标签或失去活动状态会暂停；标签仍在时保留播放位置和设置。原生控件卸载时解除播放器绑定，真正关闭标签时暂停、取消定位、移除媒体项并释放标签持有的播放器。
视频按实际画幅（包括旋转）显示，原生控件随画面而不是窗格边缘定位。
进入和退出 AVKit 全屏保留原来的播放或暂停状态，不按切换标签处理。
有系统支持的内嵌字幕时，从原生播放器的字幕菜单选择语言、开启或关闭；无字幕文件不提供语言选择。

## Markdown 嵌入媒体

用户点「加载音频／视频」才从[授权资源范围](file-viewer.md#预览资源权限)读取相对路径，
单文件最多 64 MiB（本机与获授权 SSH）。私有临时目录暂存后执行同一轨道与解码检查；
独立播放和嵌入播放各自拥有播放器，离开预览后暂停并清理临时文件。失败提示资源不可用或越界。
可显式打开源文件；远端独立播放仍遵循本页限制。

## 验证

`NativeMediaFileTests`、`NativeAudioTimingTests` 验证真实容器、解码、时间轴、轨道、字节与暂存清理；
`NativePaneRetentionIntegrationTests` 验证播放器身份和释放；`NativeMediaFileUITests` 验证原生控件、全屏及切换。
固定样本见 [TestFixtures/Media](../../TestFixtures/Media/)，设备、SSH 与图形会话条件见[测试环境](../testing-environment.md)。
验收实际解码、画面、声音输出及操作结果，不评主观音质或空间听感。
