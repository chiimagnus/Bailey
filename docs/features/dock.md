# 自由停靠、标签与窗口

各类内容以独立标签进入可自由组合的工作区。本页负责布局、移动、焦点和关闭；相关行为或状态所有权改变时同步更新。

## Invariants

- **`DockNode` 是唯一外层布局。** 面板与标签一一对应，标签内部没有第二套分屏；Diff 的统一／并排显示只是内容布局。
- **每个区域地位相同。** 使用相同的「＋」入口，工具面板移动而不是重复创建；默认三列不是固定侧栏权限。
- **移动不等于重建。** 切项目、拖动、重挂载后仍使用原内容和原生表面，不结束 Shell、不丢编辑与滚动。
- **焦点属于当前窗口和内容。** 菜单不能借用后台窗口的管理者，关闭或移动后焦点必须落在有效内容。
- **关闭先保护数据。** 文件写入失败不能关闭窗口／项目，也不能结束其中正在运行的终端。

## 布局与标签

每个项目保留自己的停靠结构，初始配置只决定新项目的布局。`Project` 拥有布局和标签，`PaneTab` 恰有一份内容；同一位置切换 A、B 标签时，以标签 ID 区分 SwiftUI 身份，而不是复用错误的原生内容。

标签重命名属于显示名称：Return 或失焦提交，Escape 取消，空名称返回自动标题。各区域标签栏仅在标签总宽度超过可用空间时水平滚动；标签全部放得下时不回弹，窗口或分屏调整大小后自动重新判断。状态变更、恢复和持久化边界见 [session-restore.md](session-restore.md)。

## 窗口与菜单

主窗口由 `WindowRootView` 的 `TerminalManager` 协调。`.focusedSceneValue(\.baileyManager, manager)` 和菜单中的 `@FocusedValue` 连接当前窗口；菜单栏「文件 → 打开文件…」（⌘O）打开当前窗口的本机文件选择面板，标签栏「＋ → 打开文件…」在发起的停靠组打开。两者均支持单／多选、只选择文件且要求已有项目。设置窗口或切换窗口后不得把 Sheet 和结果错误投到后台项目。

系统从 Finder／Dock 交给 Bailey 的本机文件请求，先检查所有窗口内已有的**本机文件标签**，即使标签属于 SSH 项目也按文件自身的机器身份判断：存在时激活原窗口／原项目／原标签，不制造第二份可写缓冲。否则在实际接收窗口的**当前项目**中新建本机标签，项目目录范围不限制能打开的文件；没有项目时不自动创建项目。恢复中的窗口先完成附着再处理文件；原 Finder 文件夹 Service 保留添加目录项目的语义。

Finder 的 `fileURL` 拖放按接收区域分流：空工作区、普通编辑／Diff、顶部工作标签栏、空停靠组及 Git 面板为**打开或复用文件标签**；每个分屏的顶部标签栏、空组内容区及普通编辑／Diff／Git／浏览器工具栏区域锁定实际接收的 `DockGroup`，新文件在该组建立标签（含空组），已打开的文件仍激活原标签而不强制搬组；Projects 面板为**文件打开当前项目的标签、文件夹添加目录项目**；Files 面板则依据行／根标题／留白准确把文件或目录**复制进目标文件夹**，不额外打开 FileTab。原生 WebKit 正文自行处理网页文件上传，Ghostty 终端正文只处理本机 Shell 路径文本，**两者上方都不挂通用 Drop**；浏览器工具栏可打开文件。唯一的 Finder `NSItemProvider<NSURL>` 异步转换由 `FinderWindowDrop.receive` 持有，再交给相应动作；始终绑定触发时的 `TerminalManager` 和 `NSWindow`。显式 `(projectID, groupID)` 在真正打开前再次核对当前项目与组是否仍有效；若用户已切换项目或原组已消失，拒绝该投放，不能无声改投另一个项目或默认组。内部 Dock 标签移动只走 `DockTabDragCoordinator`，不伪装 Finder 文件 URL。

「显示」菜单使用统一面板、项目和标签动作。保存读取聚焦内容的未保存状态；设置窗口或空工作区的关闭仍使用系统窗口关闭语义，不强行路由到某个工作标签。

关闭工具面板不删除项目；关闭工作标签只处理它自己的内容。关闭窗口与应用退出先等待真实保存，失败保留窗口；原生关闭通知仍须到达 SwiftUI，不能因自定义保护截断窗口生命周期。
