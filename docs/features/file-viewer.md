# 文件查看与预览路由

从 Files、Finder 或 ⌘O 打开文件。此页维护文件标签的读取、格式分流、展示模式与预览资源权限；
源码编辑、保存和格式专属行为分别由下列页面维护。

## Invariants

- **文件身份包含机器、路径和所属标签。** Finder 打开的 Mac 文件即使位于 SSH 项目中也使用本机后端，
  不与同名远端文件合并；晚到读取或资源结果不能跨目标、连接或版本发布。
- **每个文件标签只有一份可写正文。** 源码、预览及 Dock 并排共用文本、Undo 和保存状态；
  不另建可写副本或标签内部的分屏。
- **重挂载不是关闭。** 当前内容由标签持有，切换或移动保留其身份；真正关闭、接受不同版本或跨格式改名时
  释放被替换的内容及任务。输入焦点按真实活动控件处理，浏览不自动激活其它分屏。
- **预览不扩大访问权限或写回源文件。** 显式保存、导出和运行使用各自的确认入口。

## 格式与展示模式

| 文件 | 默认展示与入口 | 详细契约 |
| --- | --- | --- |
| `.md`、`.markdown`、`.mdx` | 源码；可预览或并排 | [Markdown](markdown-preview.md) |
| `.csv`、`.tsv` | 原生表格；可源码或并排 | [CSV／TSV](csv-table.md) |
| `.svg` | 矢量图；可源码或并排 | [SVG](svg-preview.md) |
| `.html`、`.htm` | 源码；可静态预览或并排 | [HTML](html-preview.md) |
| 栅格图片、GIF | 图形预览；静态图片可标注 | [图片](image-preview.md)、[标注](image-annotations.md) |
| 音频、视频 | 本机原生播放 | [音视频](media-playback.md) |
| 其它可编辑文本 | 原生源码 | [文本编辑器](editor.md) |

前台主窗口当前活动的可预览文本标签使用 File 菜单 `⌘⇧V` 在源码与预览间切换；
并排时切回源码。文件标签右键可指定源码、预览（表格显示为「显示表格」）或并排。
只读文本也可切换；输入法组合尚未提交的表格不切换或关闭并排。
普通文本、图片、音视频、终端和浏览器不参与此命令。无有效活动文件时置灰，不操作后台标签。
`Project.setFilePreviewMode` 统一协调 `FileTab` 与 Dock companion；跨格式改名清理不再适用的模式。
重启采用各格式默认模式，并排不持久化，见[窗口恢复](session-restore.md)。

## 按需读取与重载

创建标签或恢复会话只建立身份，首次显示或非视图消费者需要正文时才共享一次初读。
IO 与解码离开主 actor。所属窗口成为 key window 才检查外部变化；在途读取不被焦点事件取消，
同目标重复刷新合并，完成后最多补读一次。其他窗口不会被连带读取。
SSH 重连只恢复已请求过的读取，不预读从未消费的后台标签；初读期间改名继续读取新路径，
过期任务不能清除新任务。文件不可用后重新创建，新的读取仍可恢复。
真正重载替换读取任务时，同目标的文本等待者跟随新任务；机器、连接或路径改变则拒绝旧操作。

格式分流以实际字节、解码和明确的文件类型为准，不让伪装后缀绕过容量上限。
媒体候选先做 AVFoundation 检查；栅格候选失败后合法文本仍可按原编码读取。
文本读取及编码限制见[文本编辑器](editor.md#读取与编码)，保存与冲突见[文件保存](file-saving.md)。
从文件树单击可在其它 Dock 组显示常规 FileTab，不抢走仍可见的 Files 焦点；双击或显式打开才交接。
不另建临时预览标签，详见 [Dock](dock.md#布局与标签)。

## 预览资源权限

Markdown 和静态 HTML 使用 `PreviewResource`，从文件所属 backend 读取相对资源。
文件在项目内时允许项目内的跨目录相对路径；Finder 打开的项目外文件仅允许其父目录范围。
解码并规范化相对路径后，实际目标仍须是授权目录内的普通文件；拒绝越界路径、外部 URL、
绝对资源路径、URL 查询参数、空路径、反斜线、NUL 及越界符号链接。
SSH 在原机器核验并有界读取，不回退到本机；每次资源命令的超时为 25 秒。
已知断线时不授权新的资源读取。每类资源有自己的字节／像素预算。

所属窗口重新激活时，Markdown 和具有可刷新引用资源的 HTML 更新资源请求，
不写回源码或刷新其它窗口。HTML 保留阅读位置；旧版本的解析或资源结果不发布到新版本。
显式链接导航与自动加载资源是不同动作，详见[Markdown](markdown-preview.md)和[HTML](html-preview.md)。
