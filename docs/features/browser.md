# 浏览器与开发服务

浏览器以工作标签承载网页及开发服务。本页负责 WebView、地址处理和导航；导航、重挂载或服务打开方式改变时更新。

## Invariants

- **浏览器标签拥有 WebView。** 切项目、移动停靠标签和 SwiftUI 重挂载复用同一实例，不重新导航。
- **保留当前页面状态。** 表单、滚动和前进后退历史不能因界面重新挂载而丢失。
- **搜索是明确的网络操作。** 搜索词发送给 Google，不把私人终端内容自动填入搜索。
- **运行中保留与重启恢复不同。** 跨进程只重新打开保存的网址，不承诺恢复表单或网页运行状态。

## 地址与导航

地址栏区分明确 URL、主机名和搜索词。新标签与系统默认浏览器入口各自完成对应动作，不能只改显示文字。菜单中的聚焦地址栏、重新加载和停止加载作用于当前选中的浏览器内容。

## 开发服务

用户输入服务网址打开页面；远端服务需要转发时，在设置中配置并启用[长期隧道](tunnels.md)，再访问本机地址。隧道独立于终端和浏览器标签，不因导航创建或关闭。

网页加载成功不能证明 SSH 文件后端或隧道始终正常。机器、连接和主机信任边界分别由 [ssh.md](ssh.md) 与 [SECURITY.md](../../SECURITY.md) 维护。

## 验证

使用可控本地页面，检查内容、未提交表单、滚动和前进后退历史；仅比较 WebView 对象身份不够。覆盖浏览器→文件→浏览器、跨项目和拖动。跨进程恢复另测网址，明确不恢复运行时状态。

`PaneRetentionTests` 与工作区内容身份回归覆盖相应自动化部分；实际导航和系统浏览器交接按 [testing.md](../testing.md#人工回归) 验收。
