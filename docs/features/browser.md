# 浏览器与开发服务

浏览器以工作标签承载网页及开发服务。本页负责 WebView、地址处理和导航；
导航、重挂载或服务打开方式改变时更新。

## Invariants

- **浏览器标签拥有 WebView。** 切项目、移动停靠标签和 SwiftUI 重挂载复用同一实例，不重新导航。
- **保留当前页面状态。** 表单、滚动和前进后退历史不能因界面重新挂载而丢失。
- **搜索是明确的网络操作。** 搜索词发送给 Google，不把私人终端内容自动填入搜索。
- **运行中保留与重启恢复不同。** 跨进程只重新打开保存的网址，不承诺恢复表单或网页运行状态。
- **展示网页不等于网页接收键盘。** 活动工作标签、浏览器地址栏、
  WebView 正文和网页输入控件的输入意图分开，临时地址输入不产生另一份活动组或原生焦点镜像。

## 地址与导航

地址栏区分明确 URL、主机名和搜索词。新标签与系统默认浏览器入口各自完成对应动作，不能只改显示文字。
菜单中的聚焦地址栏、重新加载和停止加载只作用于活动 Dock 组中的浏览器。
地址栏与正文按既有明确动作请求输入焦点，不从“展示这个 BrowserTab”自动推导；
真正的交接由其原生控件执行。地址栏与正文的延迟焦点请求执行前再次检查前台窗口和所属活动组，
不能在用户转入工具或其它窗口后抢回输入。原生视图挂载、窗口成为 key window 或重新显示时，
只继续当前未完成的聚焦请求；成功获得 AppKit 第一响应者后才消费该次请求。
视图卸载时注销窗口监听，不再固定次数轮询，网页与地址文字仍由原标签保存。
具体 AppKit／WebKit 就绪判断仍属浏览器，不上收到窗口通用焦点管理。

外部 Finder 文件落在**网页正文**时仍交给原生 WKWebView（包括 HTML 文件上传与网页拖动），
不经过窗口通用打开；拖到 Bailey 浏览器工具栏、工作标签标题等普通区域才打开本机文件。
通用 Drop 只注册在这些明确的 SwiftUI 区域，不能通过全窗口覆盖或屏幕坐标猜测 WebKit 的事件所有权。

## 开发服务

用户输入服务网址打开页面；远端服务需要转发时，在设置中配置并启用[长期隧道](tunnels.md)，
再访问本机地址。隧道独立于终端和浏览器标签，不因导航创建或关闭。

网页加载成功不能证明 SSH 文件后端或隧道始终正常。
机器、连接和主机信任边界分别由 [ssh.md](ssh.md) 与 [SECURITY.md](../../SECURITY.md) 维护。

## 验证

使用可控本地页面，检查内容、未提交表单、滚动和前进后退历史；仅比较 WebView 对象身份不够。
覆盖浏览器→文件→浏览器、跨项目和拖动。跨进程恢复另测网址，明确不恢复运行时状态。

`NativePaneRetentionIntegrationTests` 核对 WebKit 导航历史、Favicon、对话框和重挂载原生对象；
`WorkspaceRetentionUITests` 还验证反复 ⌘L、命令面板接管与归还地址栏的实际键盘输入。
`WorkspaceRetentionUITests` 在真实 WKWebView 中填写未提交表单、切换文件标签再返回，
核对表单保留且文件字节不变。
`WorkspaceRetentionUITests` 还从真实 Finder 向网页 `input[type=file]` 投放文件，核对上传文件名、
**未生成额外 FileTab／切换项目**和原磁盘字节。浏览器工具栏另验证普通文件打开与正文读取；
仅看到网页上传成功不足以证明上层没有重复消费。
实际导航和系统浏览器交接按 [testing.md](../testing.md#人工回归) 验收。
