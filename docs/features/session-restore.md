# 窗口恢复与终端历史

窗口快照记录用户如何组织项目与标签，不是运行中任务或未保存文本的备份。持久化内容、触发、格式或恢复行为改变时更新本页。

## Invariants

- **快照只保存明确支持的状态。** 项目、标签内容描述、停靠布局、选择及编辑器位置；不保存运行中的进程、网页表单或未保存文本。
- **语义变化才触发保存。** 普通重绘、Git 状态或逐键输入不反复写窗口快照。
- **窗口快照与文件保存分开。** 500ms 合并保存只用于快照，不是文件内容自动保存定时器。
- **恢复不复活旧任务。** 文件和 Diff 重新读取，浏览器重新打开网址，终端启动新 Shell。
- **隔离实例不共享残留快照。** 每次测试有自己的身份，只有显式重启测试才复用同一个测试 ID。

## 快照写入与读取

`WorkspaceApplication` 汇集已登记窗口的快照，经 `SessionStore` 保存；各 `WorkspaceWindowModel` 只提供所属窗口的快照与历史。SwiftUI 中间 View 构造不消耗恢复队列，实际登记仅认领一次，末窗关闭仍保留可重开的最后快照；见 [架构](../architecture.md#唯一所有者)。项目、标签、停靠、工作目录、文件路径和浏览器网址的实际更改经 500ms 防抖合并；关闭窗口与应用退出保存最终状态。

活动 Dock 组与原生 first responder 是瞬时状态，不进入快照；树行选中／悬停／展开不自动等于焦点或快照保存请求，纯区域聚焦不写盘。恢复时重新选择有效区域，不宣称恢复系统键盘焦点。

点击已经可见的工作分屏仍会更新最近标签和会话上下文，但不会单独请求快照。组内展示标签确实改变时由 Dock 树请求保存；下次布局／标签快照或关闭窗口时一并记录最新工作上下文。

使用当前存储键与格式，不增加旧版本解码或迁移，不主动删除用户原始快照。Diff 快照统一记录来源类型（工作区／暂存区／提交首父差异／提交原文／提交对工作区），恢复时在原机器和路径重新读取；同一文件的不同来源是独立标签。历史原文恢复后仍只读，不把历史文件当成工作区编辑器。恢复时过滤无效停靠引用。已移除的 Info 面板引用只过滤自身，不能导致其他面板、标签或分屏位置整体回退。

关闭前文件保存是独立的数据保护步骤，见 [editor.md](editor.md#保存与关闭)；有快照不代表编辑内容已经写盘。

本机文件可以作为标签放在 SSH 项目里。现有 `ProjectSnapshot.TabSnapshot` 使用可选 `localFile` 标记保留 Mac 后端身份，恢复时仍从 Mac 磁盘读写，不随项目的 SSH 后端重绑；旧快照没有该键时保留其原有项目后端解释。旧单文件 `pinnedFile` 项目和窗口布局不迁移。

Finder／Dock 的外部打开请求不是工作区快照。冷启动及末窗关闭后收到的文件请求，会先等待已经保存的窗口完成创建和原生窗口附着，再检查所有恢复文件标签是否已有目标；避免同一文件被提前打开为第二份可写缓冲。该等待只用于应用窗口生命周期，不新增持久化队列或任意重试计时器。

## 终端历史

回放默认关闭，启用后由 `TerminalHistoryStore` 单独持久化输出。正常历史位于 Application Support 下的 `Bailey/`，不是普通偏好文件；它只能恢复显示内容，不能恢复原进程。

终端输出可能包含凭据或私人数据，不默认采集、不提交测试日志中的真实输出，见 [SECURITY.md](../../SECURITY.md)。

## 测试实例

`BaileyInstanceMode` 识别 `--isolated-ui-test` **或**有效 UUID 的 `BAILEY_UI_TEST_RUN_ID` 环境变量。隔离进程以专用 UserDefaults suite 保存窗口快照，并使用临时终端历史；不读取正式 Bailey 的窗口，也不启动已保存隧道。

刻意测试跨进程恢复时，两次启动传入同一有效 UUID。使用 `open -a <测试 App> <文件>` 验证真实 Launch Services 文档事件时，先确认正式 Bailey 已退出，再以 `open -n -a` 配合 `--env BAILEY_UI_TEST_RUN_ID=<UUID>` 启动测试 App：不要同时使用 `--args`，以免系统文件事件丢失。它只隔离数据，不隔离 Bundle ID、鼠标、键盘或图形会话；完整测试边界见 [testing.md](../testing.md#隔离环境)。

## 验证

`SessionStoreTests` 检查当前快照和隔离标识，工作区 UI 测试检查标签、窗口及保存归属。真实重启另外核对布局、选中内容和位置；分别报告可以恢复的显示状态与不会恢复的工作。
