# 设置与配置文件

本页维护普通偏好、工作区初始值、配置文件和即时应用。新增设置或改变读写方式、默认值、传播路径时更新；窗口快照见 [session-restore.md](session-restore.md)。

## Invariants

- **`AppSettings` 是唯一偏好来源。** View 不另存一份全局设置，原生表面由所属窗口应用变更。
- **配置不是工作区备份。** `~/.config/Bailey/config.toml` 保存偏好和布局初始值，不承载项目快照或未保存文本。
- **写入不能破坏手工配置。** 保存偏好使用原子写入并保留手工调整的工作区字段；失败保留原文件。
- **初始布局只影响新项目。** 已有项目按自己的停靠状态恢复，不因设置改变被重置。
- **只有一个应用身份。** Debug 和 Release 共用 `chiimagnus.bailey`；测试模式不代表全局偏好也已隔离。

## 设置窗口

`⌘,` 打开系统 `Settings` 场景。设置 UI 参考 Tinycast 的原生分组侧栏、搜索与导航历史，及 Zed 按具体设置项定位的交互：SwiftUI `NavigationSplitView` 左侧为偏好和连接分类，右侧为独立滚动的系统表单。侧栏搜索可按中英文设置名称与别名匹配具体控件，选择结果会进入对应页面并滚动到该行；`⌘F` 聚焦搜索，`⌘[`／`⌘]` 在历史页面中前进后退。系统默认侧栏折叠按钮被移除。隔离测试实例不显示手机通知入口及相关搜索结果。切换页面不替换 `AppSettings`，端口转发表单作为设置窗口的 Sheet 保留编辑状态，后台转发不随页面消失而停止。

通用页提供 SwiftUI 原生分段外观选择、语言、工具栏和确认后恢复默认；终端页提供配色、字体、加粗预览、光标、Option/Meta 与历史恢复；工作区页提供面板字号、Git 文件布局和自动折行。通知页独立管理钥匙串中的 Bark 地址。普通表单使用 SwiftUI 控件，只有终端字体加粗的准确字形预览需要 CoreText/AppKit。

恢复默认只作用于 `AppSettings` 及原有语言偏好，不删除 `tunnels.toml` 或钥匙串通知地址。语言仍需手动重启，其他偏好遵循原有即时生效规则。设置窗口遵循 macOS 原生 `Settings` 场景的固定尺寸行为，不再添加无效的 AppKit 窗口缩放桥接；较长表单在右侧滚动。

## 布局配置

窗口协调者将初始配置显式传给项目，项目不自行读取全局布局。检查组数量、权重、选中项、工具唯一性和必需项；边缘范围为 `0.05...0.4`。无效工作区配置整体退回默认值并记录错误，不能部分应用。

## 设置传播与旧键

Git 检出提交的“总是接受”写入 `git.always-accept-checkout`，默认关闭，仅略过游离 HEAD 确认。Tag 推送前的“以后总是继续”写入 `git.always-proceed-push-tag`，默认关闭，仅略过远端分支包含关系的启发式警告，不绕过 Git 真实推送权限和错误。两项偏好独立，重置设置均恢复关闭。

终端字体、配色、光标和 Option-as-Alt 变化即时作用于现有原生表面，不重建 Shell。主题与控件规范见 [ui.md](../ui.md)。

现行字体加粗键为 `terminal.font-thicken`；不再读取旧字体 UserDefaults 或旧 `font-thicken` 键。语言及 Diff 偏好使用的现有 UserDefaults 不属于旧字体迁移，不能一起删除。

应用语言改变需要重启；重启前保存窗口快照，仍不能承诺保存未成功写盘的内容。界面中英文、系统语言跟随和回退规则见 [ui.md](../ui.md#本地化)。

## 隔离与关联数据

普通配置目录固定为 `~/.config/Bailey/`。`--isolated-ui-test` 隔离窗口快照和终端历史并跳过保存的隧道，但**普通设置仍共享**；需要改设置的测试必须使用独立 Home，并核实实际读写位置，见 [testing.md](../testing.md#隔离环境)。

隧道规则独立存储在 `tunnels.toml`，不并入普通配置；其生命周期见 [tunnels.md](tunnels.md)。

「手机通知」支持逐条添加、移除多个 Bark HTTPS 推送地址（或填写官方设备 Key），并对所有已配置地址发送测试通知。支持官方及自建 HTTPS Bark 服务器。设备 Key 与地址列表统一存于 macOS 钥匙串，配置文件、日志和实际请求 URL 均不包含 Key；界面只展示主机名和 Key 后四位。地址列表为空时不推送；普通设置重置不删除钥匙串凭据，需逐条明确移除。`--isolated-ui-test` 隔离实例不访问手机通知设置，也不转发通知，避免触及用户真实凭据和设备。

## 验证

`AppSettingsTests` 使用临时配置检查默认值、往返、无效类型、手工布局保留及写入失败；`SettingsNavigationTests` 检查分类、设置搜索（中文／英文、多词、无结果、隔离模式隐藏项）、导航历史以及端口编辑的边界和冲突。原生验收需核对五个分类的所有现有控件、中英文／深浅色、最小尺寸、键盘与 VoiceOver、重开设置和实际修改后的持久化；真实设置传播还应验证修改前后使用的是同一终端进程、原生显示确实变化、非目标设置没有被重写。

实现入口：[AppSettings.swift](../../Bailey/App/AppSettings.swift)。统一验收见 [testing.md](../testing.md)。
