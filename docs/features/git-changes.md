# Git Changes 与提交

维护工作区、索引、冲突、资源菜单和提交草稿。
仓库状态见 [Git](git.md)，Diff 展示见 [Diff](diff.md)。

## Invariants

- **暂存区、未暂存区和冲突独立。** 同名路径不能合并为同一目标，混合选区不能偷偷执行部分写操作。
- **导航不等于编辑。** 展开、选择、键盘游标和展示的 Diff 分开；命令使用实际目标。
- **弃置与清理必须确认。** 保存保护与文件指纹校验不能绕过。

## 文件列表与缓存

Git Changes 与 Files 一样由状态模型持有派生树；过滤、分组与目录折叠改变时重新生成，
游标、选择、Graph 展开和相同的 Git 状态刷新复用既有行，不在 SwiftUI 更新时反复遍历全部路径。
目录／多文件选择按路径组件和集合索引解析，Stage、Unstage 与 Discard 仍逐项验证当前仓库、
状态和文件身份，不以忽略大量文件作为性能前提。
Changes 的目录索引、文件状态及父目录状态随 Git 快照在后台准备；
缓存恢复复用索引，仍需重新核验仓库才能执行写操作。共享路径树预生成压缩行与子树边界；全部展开直接复用已有行，折叠跳过隐藏子树，不再遍历并重建目录。
目录菜单查询快照中的路径和未跟踪状态索引；活动文件定位、键盘游标和选区共用可见行索引，
不反复扫描整棵树。实际写入仍重新解析选区及核验目标。

## 未提交改动与文件菜单

MERGE、STAGED、CHANGES 标题右键与顶部更多菜单都提供储藏、复位和清理表单；标题原有悬停按钮不增加。
储藏消息可空，默认包含未跟踪文件；
复位默认 Mixed（只重置 index），Hard 必须明确选择并遵循历史复位的保存保护。无 HEAD 时不能复位。

Clean 使用 Git 永久删除未跟踪文件，默认包含目录，不删除被忽略文件，也不移到废纸篓。
它不替换原逐文件 Discard：后者仍从 index 恢复已跟踪文件，本机未跟踪文件仍移至废纸篓，
SSH 删除仍经过审核。Git 文件夹和文件行共用右侧操作按钮：CHANGES 提供丢弃与暂存，
STAGED CHANGES 提供取消暂存，MERGE CHANGES 提供标记已解决（暂存）。点击文件夹名称只展开或折叠；
按钮与右键菜单作用于当前分组中该文件夹的文件，丢弃仍需确认，重命名仍处理新旧路径；
搜索时只操作当前匹配的文件，不扩大到隐藏文件或其它目录。
压缩目录可逐段右键：目录动作和忽略规则使用所点段的真实路径，
资源操作只收集当前分组与过滤条件下该段的后代；普通点击仍展开或折叠整行末级。

Git Changes 普通单击、Space／Return 明确浏览对应的 Staged／Unstaged Diff，
右键不重复提供「Open Changes」；「Open File／Open Conflicted File」仅在工作文件可打开时显示，
已删除的本机文件仍可通过「Open HEAD File」读取 HEAD 原文，不提供无效的文件打开入口。
其他 Worktree 文件的默认 Diff 同样由点击／Space／Return 打开，
不再重复提供「Open Working Changes／Open Staged Diff」右键项。
上述 Diff 浏览不激活另一个仍可见的内容组；⌘点击切换资源多选，鼠标 Shift 按锚点范围增减，
键盘 Shift+↑／↓ 按相邻行逐步增减，⌘A 选择当前可见资源，Escape 仅清除资源集合。
普通 ↑／↓ 只移动键盘游标，←／→ 操作目录，不打开 Diff 或改变 Selection；
目录节点可参与多选，执行操作时仅展开当前分组和过滤范围内的后代路径。
选择行、展开目录、Diff 已展示和当前原生第一响应者各自独立；
鼠标明确浏览的文件保留选中底色，已显示 Diff 不另绘第二条灰底；
切换 Dock 活动文件或 Diff 标签时，若当前 Git 仓库对应的资源仍可见，
Git Changes 自动定位该行并替换旧选择；暂存与未暂存的同名文件按 Diff 来源区分。
未匹配、跨机器或不可见的资源不伪造选择，自动定位不抢原生键盘输入；
方向键只移动当前行的主题细边框，不擅自改选或打开文件；
不改变所显示的 Diff。游标按仓库、机器范围、分组和完整路径区分，不能把同名的暂存、
未暂存或远端文件混为一行。提交说明和过滤输入框取得焦点后，方向键与文字输入仍属于输入框。
显式「Open File」和选择 Diff 标签继续切入目标内容；仅浏览 Diff 不修改 Git index／HEAD，
Stage／Unstage／Discard 行按钮和右键菜单在目标处于已选集合时作用于该集合，
目标不在集合内时只操作该行；分组标题的 Stage All／Unstage All／Discard All 仍作用于整组。
系统 File 菜单的「Stage All Changes」（⇧⌘Y）与「Commit Staged」（⌘Return）
面向当前窗口选中的项目，无需让 Git 面板获得焦点；
Stage All 需要有效仓库状态、未暂存更改且无进行中的 Git 操作；
Commit Staged 需要暂存更改、有效提交消息及当前操作许可。
Stage All 暂存整个仓库的未暂存更改（包括未跟踪文件），不受选区、搜索过滤或目录展开状态限制；
普通 Stage Changes 没有快捷键。Diff 布局切换见 [Diff](diff.md)。
多个文件右键隐藏只打开一项 Diff／文件、HEAD 原文和单文件忽略规则，
提供复制所选绝对／相对路径及 Finder 定位（本机）；
绝对路径 ⌥⌘C、相对路径 ⌥⇧⌘C、本机 Finder 定位 ⌥⌘R 作用于有效的键盘目标，
右键菜单展开时使用本次命中对象；这些路径快捷键属于 Git Changes，不由 Git Graph 接管。
右键菜单直接执行自己的原生快捷键；菜单取消或执行完后临时目标失效，
下一次普通命令按当前游标和选区处理。
⌘C 复制当前 Git 选区的相对路径。单项菜单仍保留原能力。
STAGED／CHANGES 同一路径是两个独立选择对象；跨 STAGED、CHANGES、MERGE 的混合选区
只能进行复制／定位，不显示只对其中一组生效的 Stage／Unstage／Discard，
也不让行内批量按钮偷偷修改选区的一部分。MERGE 只能显式标记已解决，
不能借混合选择暗中暂存冲突。批量 Git 操作执行时重新解析当前条目并核对真实 Section；
Discard 仍逐文件指纹复核、原生确认，可取消且不修改未选择文件。
SSH 断连、切项目和过期状态不会退回本机路径执行。

文件右键可只读打开 HEAD 原文（有对应版本时）。
同一路径执行 `git rm --cached` 后，STAGED 的索引删除和 CHANGES 的未跟踪文件必须分别显示，
不能因为路径相同丢掉后者。CHANGES 中真正未跟踪的文件，以及包含未跟踪文件的目录，
才提供「添加到 .gitignore」；已跟踪文件与已进入索引的 intent-to-add 不受忽略规则影响，
不展示无效操作。添加时打开普通文件标签，在当前文本末尾追加精确路径规则后保存，
保留已有未保存文本与原生撤销栈；读取或保存失败不宣称已经忽略。
含换行等无法安全表达的路径拒绝自动添加。

默认仅提交已暂存内容；全部暂存并提交与 amend 由明确选择触发。顶部拉取仅快进；
冲突不能当普通修改丢弃。

## 暂存、弃置与恢复

暂存修改索引，取消暂存保留工作区。重命名同时处理新旧路径，路径参数使用 literal pathspec。
丢弃普通已跟踪文件从索引恢复，不直接等同于 HEAD；未跟踪删除执行安全确认。

`GitStatusModel` 打开丢弃确认时保存原机器、仓库、分支、HEAD 和文件指纹，确认后再检查；
确认后先完成所有 Bailey 窗口中受影响文件的保存并暂缓新写入，保存会使旧确认失效，须重新审核；
执行 Git 操作期间持续保护这些文件，防止编辑器自动保存覆盖还原结果。
同仓库的无关草稿不受影响；结束后按实际路径刷新干净的文件、工作树 Diff 和暂存区 Diff 标签。
读取失败、文件变化或连接切换不得回退本机或执行旧操作。确认呈现属于 Git 界面。

## 提交草稿

提交草稿按当前窗口、机器和仓库保留，不持久化。失败保留草稿，成功只清除本次没有被继续编辑的说明。

## 验证

`GitUncommittedActionTests` 使用真实 Git 仓库验证储藏、复位、清理及异常结果。

`WorkspaceFilesUITests` 与 `GitChangesUITests` 分别覆盖多选菜单与复制路径、
混合分组不产生部分写入、右键不改游标或选区。

Files 与 Git Changes 的路径快捷键须核对实际剪贴板结果，以及右键菜单关闭后
原选区的命令归属；Git Graph 不注册路径复制菜单。按键注册成功不等于操作成功。
`GitChangesUITests` 通过真实 Dev App 验证外部工作区、index、HEAD 变化、跨项目隔离、文件夹按钮、
命令面板取消后真实方向键／Space 导航，以及 Staged／Unstaged Diff 的不同基线。
`GitBrowsingRecoveryTests` 验证核心查询失败时文件与两侧 Diff 的真实内容、缓存和目标隔离、
写操作拒绝及恢复后的真实 index；`GitChangesUITests` 另以隔离仓库的一次性 fsmonitor Hook
制造真实核心命令超时，核对鼠标、右键与键盘仍能读取内容；
失败期间不能暂存，Retry 成功后才恢复写操作。
`GitUncommittedUITests` 验证 Stash、Reset、Clean 原生确认与实际 Git 结果；
`GitIgnoreEditorUITests` 从真实 Bailey Dev 操作普通文件标签、执行 ⌘Z 和保存，
核对原生编辑器撤销及磁盘字节；`GitIgnoreIntegrationTests` 覆盖 CRLF、特殊路径和过期目标。
完整测试入口见 [testing.md](../testing.md)。
