# 图片标注与导出

独立静态图片的非破坏性标注、图层编辑、旁车及合成输出。标注工具、版本、配对或输出改变时更新；查看与缩放见 [图片](image-preview.md)。

## Invariants

- **原图不改写。** 标注、原图和导出文件各自拥有独立身份。
- **草稿绑定实际底图版本。** 旧版本、失效确认、错误配对不得发布。
- **编辑与导出使用同一图层语义。** 合成失败不写空白文件，不静默丢失草稿。

## 图片标注

静态独立图片右键选择「标注图片」。画布有焦点时，按单键切换工具，悬停工具按钮可查看对应按键：
`V` 选择、`P` 画笔、`A` 箭头、`R` 矩形、`E` 椭圆、`T` 文字、`N` 序号、`B` 模糊、`M` 马赛克、`C` 裁剪。
画笔拖动绘线，单击落点，一笔可整体撤销或移动。选择工具可移动图层，Shift 或 ⌘ 扩选；Option 拖动仍是平移画布。
输入文字时字母仍用于输入，不切换工具；添加或取消这段文字后可继续用键盘标注。
完成保留草稿，取消恢复进入标注时的版本；画布获得焦点时系统撤销／重做使用当前图片标签的原生 Undo，文字输入仍使用其自身原生编辑命令。
⌘S、失焦保存与关闭保护保存的是相邻的 `原图文件名.bailey-annotations.json`，不改写原图。
重新打开按原图 SHA-256、尺寸及 JSON 版本恢复可编辑图层。每个图层明确记录画笔中间点数组；没有中间点时为空数组。旧旁车缺少该字段或为 null 时不迁移、不覆盖原文件。
检测到底图版本不匹配、损坏标注或保存冲突时保留草稿，拒绝写入。
SSH 保存响应丢失时只读核对实际旁车字节和底图版本，不重复提交；断线后保留待确认版本，
同一机器重连后的保存先确认旧提交，再保存后续草稿。
旁车和覆盖导出遵循[共享条件保存](file-saving.md#保存冲突与恢复)。

## 配对文件与导出

在 Files 选择原图即可一并复制、移动、重命名或删除有效的标注 JSON；同时选中两项也只执行一次。
标注不匹配、单独操作有配对的 JSON 或目标冲突时拒绝操作。
两项无法组成单个原子事务，部分失败时保留可恢复数据并显示涉及路径；本机删除将两项作为一组移入废纸篓。
「复制标注图片」将当前草稿按原像素（有裁剪时为裁剪尺寸）合成 PNG 到剪贴板，不保存标注。
「导出标注图片…」可选择 PNG／JPEG、输出尺寸、sRGB／Display P3、背景和 DPI，
默认独占创建新文件；覆盖已有导出文件须确认其版本，确认后发现变化则拒绝写入。
禁止将原图、其硬链接或已有标注关联的图片作为覆盖目标；导出不会替代标注保存。
区域预览与导出共用原图坐标和 Lanczos 像素采样；模糊依实际滤镜采样范围、
马赛克依完整单元读取相邻像素，最后才裁剪输出。视口平移不重建缩放像素网格。
Core Image 渲染任务成功完成后才接收位图；执行失败显示预览或输出错误，不把透明失败结果写入剪贴板或文件。
动画 GIF 与 Markdown 内嵌查看不进入标注态。

## 验证

`ImageAnnotationTests` 检查原图与旁车版本、编辑撤销、配对、过滤、冲突及输出字节；
`ImageAnnotationUITests` 检查实际标注输入、复制、导出及关闭。真实失败和跨格式验收见
[文件保存](file-saving.md)、[测试环境](../testing-environment.md#写入失败夹具)及[性能验收](../testing-performance.md)。
