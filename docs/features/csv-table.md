# CSV／TSV 表格

默认打开原生表格。按 `⌘⇧V` 切换源码，文件标签右键可选并排；
共用[文件查看路由](file-viewer.md)和[条件保存](file-saving.md)。

## Invariants

- **表格是同一份文本的投影。** 正文、Undo、脏状态和保存基线唯一；筛选、排序及展示切换不改写文件。
- **修改真实字段而非显示行号。** 隐藏记录、物理字段与可见选区分开，事务只改用户明确指定的数据。
- **未提交输入受保护。** 组合输入未结束不切换模式；失效草稿不得静默丢弃或按旧位置写入。
- **显示成本有界。** 原生行复用和视口列虚拟化，不为超宽表格挂载全部数据格。

## 选择与行列操作

首条记录固定作为表头。点表头选列、固定行号选行、`#` 或 `⌘A` 全选数据；
Shift 扩展、⌘ 追加。「可见数据」指未被筛选隐藏的记录及已显示的列，包括屏幕外的数据格。
行号始终对应原文件的逻辑记录，排序、筛选和字段内换行不重编号。表头菜单提供排序及筛选，并显示状态图标。
右键行号插入下一行或删除选中行；没有可见数据行时右键 `#` 插入，空文件同时建立空表头。
普通数据格没有行列结构菜单；Delete／Forward Delete 清空所选字段，不删除行列或表头。
矩形粘贴按物理字段修改，多格复制按显示顺序输出制表符分隔文本；排序与筛选不写回文件。

拖动表头只移动被拖动的一列，不成组移动多选列。拖动时仅显示插入线，不重排数据格，靠边自动横向滚动；
松开后一次提交、一次撤销，Esc 取消。列菜单可插入或删除列；右键已选整列时删除该选区，否则只删除命中列，
至少保留一列。列结构操作包含表头和隐藏行，保留未改字段与行尾。超过 4096 列时只显示前 4096 列，
其余可在源码查看，不接受列结构编辑。

## 原位编辑

双击表头或双击／Return 编辑单元格，使用同一多行输入框；表头可为空或重名。
编辑框随内容扩展至视口大小，超出时内部滚动，不调整其他列或重建表格。
Return 提交，Tab／Shift-Tab 提交并导航，Option-Return 插入换行，Esc 取消；
提交后无需再点击表格即可导航、撤销或重做。只读时仍可原位查看、选择和复制完整字段。

## 布局

表格跟随 App 主题，正文等宽，有限十进制及科学计数值使用主题色。表头、行号、数据格共用背景，
以字重、次级文字和细网格线区分。真实换行按多行显示，行高随最长字段的可见行数变化；
行高、固定行号栏及留白按实际字体测量，字号独立于源码及终端。列宽按表头及有限数据样本的最长文本行适配，可拖动边界调整，手动宽度按基准字号保存。
原生行复用与视口列虚拟化共同限制数据格数量，横滚只更新进入或离开视口的列。
批量列变更时暂停数据格布局，只执行一次最终原生布局；换色、字号及列宽变化保留选区、活动输入和正文。

## 数据保护

合法 UTF-8 优先于首行 `coding:` 字样，不阻止显式转换编码；UTF-8 解码失败时仍可识别已有编码声明。
分隔符自动识别优先采用结构一致的记录；初始采样为 16,384 个 UTF-16 码元，
若不足两条完整记录则在解析预算内继续至两条或文件结束。
索引最多接收 1,000,000 个字段及 33,554,432 个 UTF-16 码元；超限报告问题，不允许表格写入。
单格和表头的普通展示按 4,096 个源码 UTF-16 码元截取，原位查看、编辑及复制仍针对完整字段。
表格事务及 Undo／Redo 保留已确定的分隔符，源码修改后重新识别；字段内出现其他分隔符不直接判为歧义。
格式错误报告原文行列；分隔符不确定、格式不合法或无法证明编码无损往返时仅可查看。

已接受的字段输入和粘贴由文件标签持有；保存、关闭、切换模式及移动前先处理，不因卸载而取消。
断线结束编辑并保留草稿，重连仍按原版本保护保存；编码转换无法表示草稿时拒写。无法应用的字段草稿可查看、复制、
重试或明确丢弃；不得按旧位置盲写或静默关闭。原字节往返证明随载入及确认发布更新，同字节保存不使索引失效。
索引重建保留原生表格，暂时清除旧行与选区；真正关闭或接受外部替换时同步释放旧投影，不等待视图卸载。

## 查找与替换

按 [⌘F](find.md) 打开字面查找，不区分大小写和变音符号。
CSV 查找按筛选后的行列顺序统计匹配格并循环导航（含屏幕外数据），通过二分定位当前格，清空查询或收起浮层不再保留旧搜索结果。
收起后排序／筛选不自动跳到匹配。替换前显示实际出现次数，范围可选择「可见记录」「当前选区」「全部数据记录」。
当前选区固定于选取时，可通过「使用当前表格选区」更新，不随导航改变。只有全部数据记录包含隐藏行；
三种范围均不含表头或超出显示上限的列。单次替换从当前格查找可见命中，同格连续替换延续字段内偏移；
全部替换才批量处理指定范围（含允许的隐藏行）。清空和替换均一次提交、一次撤销，不改写未选字段。

`DelimitedGridInteractionTests` 验证原生选择、编辑、布局与组合输入；`CSVPreviewUITests` 验证真实菜单、拖动及保存字节。
