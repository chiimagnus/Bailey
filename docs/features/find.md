# 内容查找与替换

`⌘F` 打开当前内容的共享查找浮层。本页维护 FindWidget、查询入口、焦点与源码查找契约；
命令面板的项目文件搜索见[命令面板](command-palette.md)。

## Invariants

- **系统 ⌘F 是唯一打开入口。** 只作用于当前窗口实际活动内容；浮层内部负责导航、替换和关闭。
- **查询属于当前内容。** 不搜索隐藏源码，不把后台窗口、旧选区或只读视图变成可写目标。
- **浮层不参与正文布局。** 展开替换不改变视口或阅读原点；关闭时仅恢复仍有效的原生输入目标。
- **过期结果不发布。** 替换使用原有编辑与撤销链，不扩大用户选定的范围。

## 操作

按 `⌘F` 在当前内容右上角打开查找浮层。查找框内 Enter／Shift+Enter 跳到下一处／上一处，
也可点击上下箭头；Esc 或关闭按钮退出。可写内容用左侧箭头展开替换，替换框内 Enter 执行单次替换。
默认宽度 350 pt，拖动左边缘调整，双击恢复；宽度不足时隐藏部分按钮和计数，拖宽浮层或扩大窗格即可使用完整控件。
按钮悬停显示本地化说明。

选中有效文字后按 `⌘F` 填入查询，再次按下也会采集主动选区。无有效选区、只有自动匹配选区或已在查找框输入时，
保留查询并聚焦全选。源码、Diff、CSV 和 HTML 的自动填入限非空单行选区（少于 524,288 个 UTF-16 码元）；
正则模式按字面转义，CSV 还可使用单格或原位编辑中的文字。终端选区由 Ghostty 处理。

| 当前内容 | 查找与替换能力 |
| --- | --- |
| 源码／Diff | 大小写 `Aa`、整词（带下划线的 `ab`）、正则 `.*`、选区；可写正文支持替换及保留大小写 `AB` |
| [CSV／TSV](csv-table.md#查找与替换) | 字面查找；支持三种替换范围 |
| [HTML 预览](html-preview.md) | 查找排版后的文字；只报告是否找到 |
| 终端 | 查找屏幕与滚动历史；见[终端](terminal.md#入口与输入) |

只读内容不提供替换。Markdown 阅读预览、SVG 图形、图片、音视频及浏览器尚未接入此查找入口，
不借用隐藏源码。

## 源码与 Diff

源码与 Diff 共享后台匹配与完整压缩位置索引，导航不重复扫描全文。仅在 TextKit 实际可见范围绘制匹配背景；
过期查询与正则引擎失败均不发布部分结果。替换使用唯一原生正文和 Undo 栈。
选区范围随可靠的原生字符编辑更新；无法维持原范围时关闭查找，不扩大到全文。

## 验证

`TextFindTests`、`DelimitedTablePresentationTests`、`HTMLFilePreviewTests` 验证查询、范围、替换及取消；
`FindWidgetUITests` 检查真实选区、快捷键、浮层及焦点。终端与 Diff 的具体焦点边界由各自功能页维护。

- **查找与替换**：`TextFindTests` 验证完整压缩索引、跨页位置、零宽正则、Unicode、取消与只读；
  32 MiB 级密集匹配核对总数、首尾导航、超长单行可见字形绘制与双向横滚像素。
  150–900 pt 窗格及亮暗外观核对浮层不挤压正文、控件不重叠、输入框对齐、足够宽度下完整控件可用；
  `FindWidgetUITests` 验证中英文实际窗口、固定选项符号与本地化说明、唯一 `⌘F` 入口和替换保存。
  源码、CSV、HTML、Diff 与终端各查找后端回归当前内容路由、重复打开采集主动选区、自动匹配及查询框焦点保留；
  源码与 Diff 核对整词、大小写、正则及选区失效；`DelimitedTablePresentationTests` 和 `DelimitedGridInteractionTests`
  核对 CSV 字面匹配、筛选后的计数、二分定位及首尾循环，区分匹配格数与字段内出现次数。
  可写内容另核对限定范围、连续替换、原字节和独立 Undo／Redo。
