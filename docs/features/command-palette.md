# 命令面板与文件搜索

⌘P 打开当前窗口的命令面板，用于执行内置动作、搜索本机或 SSH 项目文件和定位已打开的终端。搜索、选择、命令或入口变化时更新本页。

## Invariants

- **文件搜索绑定当前机器和项目。** SSH 文件索引只通过已绑定的远端后端查询，断线或权限失败不回退到 Mac；本机/远端用户主目录及文件系统根不执行全盘扫描。
- **显示与执行使用同一选择。** 键盘高亮、鼠标选择和 Return 必须指向同一条结果。
- **命令复用真实动作。** 新建文件、打开标签或定位会话应进入已有工作区路径，不再实现一套业务规则。
- **结果仍属于发起目标。** 项目改变后，旧索引或晚到的结果不能打开其他项目中的文件。

## 搜索与交互

面板呈现内置命令、当前项目文件和终端会话。「添加文件夹」与系统 ⇧⌘A 共用原生目录选择器，只添加项目；它不负责把 Mac 单文件创建成 `pinnedFile` 项目。项目外任意本机文件由「文件 → 打开文件…」（⌘O）或标签栏「＋ → 打开文件…」选择，文件搜索结果仅来自当前项目所连接的机器。文件索引在出现非空查询时加载：本机保持原 Git tracked/非忽略 untracked 规则；SSH 复用同一文件范围和远端 Git 查询，只有明确不是 Git 仓库才有限遍历远端目录。远端输出与目录扫描有上限，超过上限或连接异常会明确提示，不伪装完整结果；Files 的 `files.exclude` 不影响搜索。关闭面板或切换目标会取消旧任务，异步回写及点击 SSH 结果打开前再次核对项目、根和连接代次。面板保持打开时，本机 Files 已缓存目录的实际变化会使文件索引失效并重新查询；本机未展开、未缓存深层目录的创建／删除／重命名事件也会使索引按需重查，但不会导致 Files 为搜索遍历整个目录树。纯内容修改与未变化的已读目录不重复索引。SSH 仍依靠现有目录刷新，其持续事件通知另按 #40 的 SSH 阶段验证。文件及会话的匹配信息可包含目录；用户内容按原文展示，不作为本地化键。

方向键改变选择，Return 执行动作；Escape 先清除查询，再关闭空查询的面板。鼠标、键盘和底层终端焦点不能互相干扰，新增动作应沿当前窗口的管理者接入。

面板从出现起便**声明临时输入意图**，但实际输入仍以 AppKit first responder 为准：即使搜索框的原生输入焦点尚未就绪，后层 Files／Git 也不能先接管键盘。临时输入不修改当前展示标签、活动组或列表游标，也不隐式打开文件。取消只恢复本次被打断、仍属于前台活动内容的可见原生控件，包括 Files 与 Git Changes／Graph 当前行的键盘接收视图；选中行不因此执行文件打开或 Git 操作。执行命令后，焦点交给命令实际切入的区域；若目标未变，则继续使用原有效内容。已有新焦点不允许被晚到的旧恢复抢回。共享 field editor 不作为稳定恢复目标，Diff 与 WebKit 则按当前实际视图归属检查。面板结束应恢复**当下有效的目标**而非仅恢复开面板时缓存的原生指针；此处描述现行行为要求，窗口统一策略尚待 [架构重构](../architecture.md#焦点协调边界) 实施。

## 验证

`ProjectFileIndexTests` 验证本机与受控远端文件索引、Git 异常、远端目录输出上限、HOME／根目录物理路径别名及遍历限额；`WorkspaceFilesUITests` 从真实中英文 App 搜索并执行「File Manager」，核对文件树方向键／Space 的实际结果；`GitChangesUITests` 验证取消后 Git 键盘导航，`WorkspaceWindowsUITests` 验证焦点恢复不跨窗口；`SharedTreeUITests` 另以明暗主题验证 Palette 接管时的原生选中与底色分离。实际面板验收还覆盖空结果、鼠标、切项目、文件打开和会话定位。不能仅断言“动作已派发”；要检查实际打开内容与最终焦点。SSH 搜索限制要包含本机同名路径的反例。
