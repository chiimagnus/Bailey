# 命令面板与文件搜索

⌘P 打开当前窗口的命令面板，用于执行内置动作、搜索本机项目文件和定位已打开的终端。搜索、选择、命令或入口变化时更新本页。

## Invariants

- **文件搜索仅支持本机项目。** SSH 项目不能悄悄搜索本机同名目录；用户主目录作为项目根时不创建文件索引，避免把整个 Home 当作普通项目扫描。
- **显示与执行使用同一选择。** 键盘高亮、鼠标选择和 Return 必须指向同一条结果。
- **命令复用真实动作。** 新建文件、打开标签或定位会话应进入已有工作区路径，不再实现一套业务规则。
- **结果仍属于发起目标。** 项目改变后，旧索引或晚到的结果不能打开其他项目中的文件。

## 搜索与交互

面板呈现内置命令、本机文件和终端会话。「添加文件夹」与系统 ⇧⌘A 共用原生目录选择器，只添加项目；它不负责把 Mac 单文件创建成 `pinnedFile` 项目。项目外任意本机文件由「文件 → 打开文件…」（⌘O）或标签栏「＋ → 打开文件…」选择，文件搜索结果仍仅搜索当前本机项目范围。文件索引在出现非空查询时才按当前本机项目加载；关闭面板或切换目标会取消旧任务，回写前再次核对项目和路径。文件及会话的匹配信息可包含目录；用户内容按原文展示，不作为本地化键。

方向键改变选择，Return 执行动作；Escape 先清除查询，再关闭空查询的面板。鼠标、键盘和底层终端焦点不能互相干扰，新增动作应沿当前窗口的管理者接入。

面板从出现起便**声明临时输入意图**，但实际输入仍以 AppKit first responder 为准：即使搜索框的原生输入焦点尚未就绪，后层 Files／Git 也不能先接管键盘。临时输入不修改当前展示标签、活动组或列表游标，也不隐式打开文件。取消只恢复本次被打断、仍属于前台活动内容的可见原生控件，包括 Files 与 Git Changes／Graph 当前行的键盘接收视图；选中行不因此执行文件打开或 Git 操作。执行命令后，焦点交给命令实际切入的区域；若目标未变，则继续使用原有效内容。已有新焦点不允许被晚到的旧恢复抢回。共享 field editor 不作为稳定恢复目标，Diff 与 WebKit 则按当前实际视图归属检查。面板结束应恢复**当下有效的目标**而非仅恢复开面板时缓存的原生指针；此处描述现行行为要求，窗口统一策略尚待 [架构重构](../architecture.md#焦点协调边界) 实施。

## 验证

`ProjectFileIndexTests` 验证本机文件索引；`WorkspaceFilesUITests` 从真实中英文 App 搜索并执行「File Manager」，核对文件树方向键／Space 的实际结果；`GitChangesUITests` 验证取消后 Git 键盘导航，`WorkspaceWindowsUITests` 验证焦点恢复不跨窗口；`SharedTreeUITests` 另以明暗主题验证 Palette 接管时的原生选中与底色分离。实际面板验收还覆盖空结果、鼠标、切项目、文件打开和会话定位。不能仅断言“动作已派发”；要检查实际打开内容与最终焦点。SSH 搜索限制要包含本机同名路径的反例。
