# 文件操作

维护 Files 的新建、复制、移动、删除及文件剪贴板。选择、可见路径和刷新由[文件树](files.md)维护。

## Invariants

- **操作绑定真实目标。** 项目、机器、连接及根范围一致；不因异步等待转向新目标。
- **创建和重命名不能覆盖同名项，包括失效符号链接与同 inode 的不同硬链接。**
  远端移动必须拒绝操作期间出现的普通目标文件；大小写改名不能仅凭 inode 相同就允许覆盖，
  失败或正常终止信号应恢复原路径。
- **拖动来源与落点分离。** Files 内拖动已选中行时使用 Selection 集合；从未选中行开始仅拖该项。
  指针反馈与实际动作一致；跨窗口、项目或机器不接受内部移动。取消及失败不删除源文件。
- **修改磁盘前保护相关草稿。** 详见[文件保存](file-saving.md#文件操作与版本绑定)。

## 新建与打开

文件菜单、命令面板和标签栏「＋」共用新建文件 ⌘N、新建文件夹 ⌥⌘N：
Files 聚焦时在选中目录内创建，选中文件时在其父目录创建；
活动编辑器文件属于当前项目根目录时在其相邻目录创建；其它情况回退项目根目录。
目录右键始终在右键目标目录创建；菜单展开期间的 ⌘N／⌥⌘N 使用本次目录目标，
不因菜单关闭而改用原选区。若项目或工作范围已切换，不在新位置创建。
「文件 → 打开文件…」（⌘O）和标签栏「＋ → 打开文件…」是**选择已有 Mac 文件并增加编辑标签**，
不创建文件／项目或改动 Files/Git 根；添加本机项目另用「添加项目」（⇧⌘A）。

## Finder 导入与树内拖放

**Finder → 本机文件管理器执行复制，不是打开编辑标签。**
放在目录行（含压缩目录的真实末级）时复制到该目录；
放在文件行时复制到其父目录；放在树留白或根路径标题时复制到当前 Files 根目录。
可批量导入文件和文件夹，源内容不移动、不删除；普通与失效符号链接复制链接本身，不递归展开其目标，
设备文件与命名管道不导入；操作不会新建 FileTab 或切换项目。
复制由 `LocalWorkspaceBackend` 在目标同卷的系统临时替换目录中完成，
再用原生不可覆盖的原子重命名发布，目录复制失败不会留下不完整的目标文件夹。
目标已有同名文件／文件夹（包含失效软链接）、来源缺失、目录自复制、
权限错误等按项拒绝并以原窗口 Sheet 报告；
投放到指向项目外部的目录链接也明确提示原因、不写入外部目录；
指向项目内部的目录链接在校验后固定实际目录作为复制目标，避免异步执行时链接改指向别处。
合法项继续，成功后由 `FileTreeModel` 刷新可见目录。
切换项目、关闭窗口或机器不符时不把操作转向其它根。
SSH 文件树拒绝 Finder 导入，不隐式上传或回退写 Mac。
同一 Files 树中的文件行和多选文件可拖到目录行、文件行的父目录或树根／留白：
默认移动，按住 Option 复制。内部拖动使用仅限当前进程的私有数据并核对原窗口、项目、连接及有效选中，
不会降级成 Finder 导入或跨窗口传输；操作完成后复用与右键菜单一致的防覆盖、脏稿保护及失败反馈。
本机文件向 Finder 拖动时为每个所选文件发布公开 Mac `fileURL`；
SSH 文件仅允许当前树内的私有拖动，不伪装本机 URL。文件剪贴板同样不支持跨机器传输。

## 后端复制与移动

本机内部复制、Finder 导入及文件粘贴共用 `LocalWorkspaceBackend` 的实体类型、
副本命名、递归检查和防覆盖规则：先在目标卷暂存并验证文件字节、符号链接与可保留的元数据，
再使用 `RENAME_EXCL` 发布，已有目标不可覆盖。同卷移动使用排他重命名保持实体身份；
跨卷先验证完整副本，再仅对未改变的来源执行删除，删除失败单独报告原件保留位置。
SSH 仍使用独立后端和已有私有副本、排他发布流程，不借 Finder 进行传输。

## 菜单与剪贴板

Files 拥有实际键盘焦点时，系统 Edit 菜单的剪切／复制／粘贴／删除／全选操作于所选文件；
⌘C／⌘X／⌘V／⌘A 与 Delete（⌫）均通过原生菜单和第一响应者执行，
文件树不再自行解析这些快捷键；独立的向前删除键（⌦）仍保留为文件树输入。
Files 右键的剪切 ⌘X、复制 ⌘C、粘贴 ⌘V、本机移动到此处 ⌥⌘V、删除 ⌫、新建文件 ⌘N、
新建文件夹 ⌥⌘N 均由当前弹出的原生菜单直接执行，没有按键重投或独立监听。
输入框、编辑器和终端沿用原生文本或终端行为；Git 树的 ⌘C 只复制其自身选区的文字，
不借用 Files 的文件剪贴板或接收文件剪切／粘贴／删除命令。
Files 右键不再重复提供文件「Open」：双击／Return 已能进入编辑器；
「Open in Default App」使用系统默认应用，与 Bailey 内打开不同，本机文件保留此项及 Finder 定位。
文件夹仍可新建文件／文件夹和粘贴；文件操作保留剪切、复制、重命名与删除。
「Copy Path」复制绝对路径，「Copy Relative Path」复制项目相对路径，两者只复制文本；
对应 ⌥⌘C、⌥⇧⌘C，本机 Finder 定位用 ⌥⌘R。
普通快捷键作用于 Files 的有效键盘选择；右键菜单展开时只作用于本次命中的单项或多选集合，
菜单关闭后不夺走终端、编辑器的键盘焦点。SSH 不提供 Finder 定位。
不提供需再次选择目录的「移动到…」、独立「制作副本」「cd Here」或展开紧凑目录的菜单。
在多选行内部右键时，切换为多选菜单：保留剪切、复制、删除和复制整组绝对／相对路径；
本机 Finder 可以一次定位所有所选项；隐藏只适用于单项的系统默认应用打开、重命名、
新建与粘贴入口。右键未选中行始终使用该行的单项菜单，
不清空原有选区或移动键盘焦点。
本机 Files 的复制／剪切将每个所选实体作为独立的系统文件 URL 放入剪贴板，
也附带路径文字；SSH 只使用私有记录和文字，不冒充本机文件。
文件剪贴板的私有记录不构成移动授权，只有进程内仍持有的来源意图、
未被改写的剪贴板版本与真实文件身份共同匹配时才能按剪切移动。
本机粘贴可从 Finder 或其它项目、窗口取得原生文件 URL：⌘V 默认复制，
仅进程内有效的 Bailey 剪切意图可让 ⌘V 移动；本机目录右键和 Files 焦点下的 ⌥⌘V
允许将公开文件 URL 明确移动到该目录。移动前协调所有窗口的脏稿，复制不触发脏稿保存。
已完成的移动从剪贴板剔除，部分失败只保留仍存在的来源以便重试；外部改写剪贴板后不回写。
SSH 仍仅允许原项目、未重连的同一连接使用私有记录，不接受本机文件 URL 或隐式上传。
**复制后粘贴到来源所在目录会生成 `name copy.ext`，再次粘贴生成 `name copy 2.ext`**（文件夹同理）；
从其他目录复制遇到同名目标仍拒绝覆盖；真实目录不能复制到自身或后代目录，
移动到原父目录不改变源实体。
删除本机文件进废纸篓，远端永久删除须在发起窗口的 Sheet 明确确认，已不存在的远端路径也会报告失败。

## 目标校验与数据保护

后端必须承担实际创建的排他性，UI 预检查不是数据保护。批量同机文件操作先合并父子重叠选择，
逐项返回成功与失败；目标目录和来源的实际父目录均不能越过项目根；
验证后通过实际父目录操作，避免软链接在等待 IO 时改指向项目外。
新建与重命名采用同一边界，仍允许操作软链接条目本身。
成功移动会维护 Files 游标、目录展开和打开文件标签；切项目后已完成的磁盘结果仍交回原窗口所有者，
旧树不接受过期行。合法文件名的首尾空格原样保留。

移动、重命名、删除前由[共享保存保护](file-saving.md#文件操作与版本绑定)等待所有受影响窗口的写入，
拒绝冲突草稿；移动期间的新保存延至路径更新后。
实际修改完成后按机器身份更新各窗口的文件标签及固定项目路径；
本机通过不同符号路径打开的同一实体也会映射到实际新路径；
成功删除的干净标签关闭，删除期间新产生的脏稿保留为只读，不允许后续自动保存重建旧文件。
重命名同步更新已打开文件的路径，后续保存写入新路径。SSH 大小写更名可能使用同目录临时项，
常规失败会回滚；机器断电或强制终止无法保证回滚，异常残留的 `.bailey-rename.*` 不自动删除。
远端删除的数据保护见 [SECURITY.md](../../SECURITY.md)。

## 验证

`FileTreeTests` 覆盖真实复制字节、文件夹/子目录、中文、同名冲突、原子失败不留部分目录、
并发唯一发布、失效来源与目标符号链接、指向目标祖先的目录链接、特殊文件拒绝、超出根路径的禁放，
以及 POSIX 根目录 `/`、相似前缀目录和禁止目录递归自复制。
签名测试 App 的 Finder 实际拖放需要逐一检查目录行、文件行、根标题、留白、
复制后的磁盘文件和 Files 刷新、冲突 Sheet、项目及文件标签数量，不能拿 `.copy` 指针反馈当复制成功。
`WorkspaceFilesUITests` 验证真实剪贴板、新建、重命名和删除结果；
实际 SSH 文件操作须核对原机器的磁盘结果。运行方式见 [testing.md](../testing.md)。
