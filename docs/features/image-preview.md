# 图片查看

打开栅格图片可查看、放大及平移，静态图片可右键标注并复制或导出。
本页维护栅格解码、共享图形视口与 GIF；矢量规则见[SVG](svg-preview.md)。

## Invariants

- **像素与原文件对应。** 先验证格式、字节和像素预算，再按视口获取详情；不靠整图无限放大或缓存全部 GIF 帧。
- **重挂载保留阅读位置。** 新文件版本才重置，旧详情任务不得替换新图。
- **图形查看只读。** 图像查看与缩放不改变原始文件。

## 读取与原像素

图片仅在确认普通文件、读取有界格式头且原始字节不超过 256 MiB 后完整读取；
预览经 ImageIO 核查首帧最多 3,200 万像素，并仅解码最长边不超过 4,096 像素的首帧缩略图，
不交给 AppKit 延迟解码整张或全部动画帧。伪装图片后缀不能绕过文本上限；
被拒绝的超大或无效图片不得清除已有未保存编辑。

文件图片和 Markdown 栅格插图共用有界的格式识别、ImageIO 缩略图与色彩／EXIF 解释。
按原像素比例显示，印刷 DPI 不参与缩放；完整静态图片保留原解码色彩空间和位深。
真实栅格格式决定文件预览，后缀仅用于大文件探测优化；改名或无后缀仍能查看。
图片候选无法解码时，合法的文本仍按原编码读取，SVG 保留可编辑源码。
JPEG 缺少主图结束标记时不显示残图，即使它还包含完整的嵌入缩略图。
PNG 缺少完整结束块、数据块截断或 CRC 校验失败时也会拒绝预览；HTML 引用的 PNG 同样执行此校验。
标签切换器只用缩略图。打开大图时先显示缩略图，需要更多像素才通过原文件的后端重新读取，
核对原始字节版本后在后台解码。100% 按当前屏幕的实际像素计算。缩回到缩略图足够清晰的倍率时，
释放原图像素并取消未完成的详情读取。
切换标签、重挂载视口或改名时，文件图片保持原来的缩放和查看位置；
改名后从新路径读取详情，图片内容变更后重新适应窗口。
符合条件的 8 位 RGB JPEG／HEIC、PNG 和普通 TIFF 放大时
只保留视口附近的原像素缓冲；平移时按需更新并取消旧任务。
PNG 按扫描行解码，交错图只合并所需区域；普通 TIFF 按条带内扫描行或相交图块读取。
两者复用同版原始字节和 ImageIO 色彩空间，不重复读取本机或远端文件。
特殊 TIFF 压缩、过大图块、与 ImageIO 缩略图解释不一致的布局以及其他不支持区域读取的格式，
保留原有预算内的整图详情。

## 缩放与平移

图片文件、内嵌 SVG 和 Mermaid 的放大查看共用原生滚动视口，不生成或写回工作区文件。
普通鼠标垂直滚轮、触控板捏合或 ⌘＋滚轮围绕指针缩放；触控板双指滚动、Shift＋滚轮及拖动用于平移。
双击在适应窗口和实际大小之间切换。
右键和辅助功能提供相同缩放动作，名称与当前值体现适应窗口或实际倍率。
栅格及 Mermaid 手动缩放为 10%～400%，适应窗口不受 10% 下限限制，
因此极宽或极高的图也能完整显示。
SVG 的倍率与矢量重绘使用[独立规则](svg-preview.md#矢量查看)。

## GIF 播放

独立 GIF 与 Markdown 内嵌 GIF 的自动播放遵循系统「播放动画图像」设置。
独立图片的右键与辅助功能均可暂停或继续，显式操作优先于自动播放偏好；
切走标签或窗口失去焦点时不推进，回到原标签后从原位置继续。
动画按需读取同一文件版本，只预取下一帧，
不把全部动画帧留在内存里。只对零时长和极短帧限速，不缩短文件指定的较长停留时间。
GIF 缺失中间帧数据时保留可读的首帧，不播放不完整的动画。
Markdown 内嵌 GIF 的额外预算见[Markdown](markdown-preview.md#阅读与富内容)。

静态独立图片的标注、配对和导出由[图片标注](image-annotations.md)维护。
