# 项目与工作范围

项目统一承载本机或 SSH 的文件、目录和工作标签。本页负责项目身份、添加及范围选择；
这些行为改变时同步更新，连接细节见 [ssh.md](ssh.md)。

## Invariants

- **只有明确添加目录才创建本机项目。** 添加目录不启动终端；
  打开 Mac 文件只创建或复用当前项目的编辑标签，不因文件父目录产生项目；重复添加目录选择已有项目。
- **项目不是终端的附属品。** 关闭全部终端或项目列表面板不删除项目；关闭项目是独立操作。
- **Files 与 Git 使用同一项目范围。** 面板移动、默认侧栏位置或终端进入同仓库的子目录，
  不能各自改变范围。
- **身份包含机器与路径。** 本机与远端、不同 SSH 端口的同名路径不能共用标签或结果。

## 所有权与范围选择

**当前实现**由窗口管理者持有项目及布局，`Project` 持有标签、文件树和组内排列；
各面板通过项目的 `PanelContext` 取得后端和身份。
项目选择、Dock 组激活、当前展示标签与真实键盘焦点是不同事实；窗口不复制一份项目可写状态。
项目的 Files 同步只使用调用方提供的当前目标许可，始终核对所属机器与 `PanelContext.Identity`，
不反向读取整个窗口模型；见 [architecture.md](../architecture.md#唯一所有者)。

项目创建时必须提供绝对根路径，SSH 主机在创建时确定。Files、Git 和命令面板始终使用该根路径，
不随终端工作目录或前台任务改变。项目名称来自所添加的目录名或 SSH 文件名；
没有独立的项目重命名或重新选根命令；同机目录实际移动／改名时更新固定路径。

### 本机资源打开与手动添加

「添加文件夹」（⇧⌘A）是明确创建／选中本机目录项目的动作；
本机文件不再作为新项目添加，SSH 单文件仍可以作为带初始文件标签的远端项目。
「添加 SSH 文件或项目」先从 `~/.ssh/config` 的主机列表选择连接目标；仅打开选择器不会连接所有主机。
需要新增主机时，先在该文件中配置 `Host`；也支持通过 `Include` 引入的主机。
选择器打开后由它接收键盘，底层 Projects 列表不得抢走焦点；没有可用主机时也可用 Escape 取消。
Windows SSH 从可用磁盘列表开始，其他主机从登录主目录开始。
可浏览目录或直接输入绝对路径并按 Return 前往；输入完整文件路径仍可添加单文件项目。
远端目录排序在主线程之外执行；输入过滤结果与行位置按当前目录和输入复用。
重复添加同一目录优先复用原项目，不启动 Shell。
Finder 投递及原生多选文件入口见 [macOS 窗口](windows.md#系统文件投递)。

## 项目列表交互

当前项目使用主题选中底色；↑／↓ 只移动项目列表的键盘游标，
Return／Space 才切换项目；Escape 关闭临时菜单，不清除键盘游标。
右键只绘制临时上下文描边，不抢焦点或切换项目；
菜单关闭后描边消失，当前项目选择仍保留。
右键关闭项目仍走已有的未保存内容保护。
项目列表增加、重排或关闭时按项目 UUID 保留有效键盘游标；后台项目被关闭时，
只清理指向该项目的游标、右键和拖动目标，不改变仍有效的当前项目。
失效游标回到当前项目，项目全部关闭时清空。
项目列表按视口懒加载，键盘游标移出视口时滚动定位。

## 切换、关闭与失败

同机目录移动／重命名通过 `WorkspaceApplication` 已登记的所有窗口传播真实成功结果，
更新属于该机器的打开标签和项目固定路径；另一台机器同名路径保持不变，不引入第二套全局文件注册表。
异步根目录查询、文件读取和动作在发布或执行前再次核对发起项目与机器身份。
切换后旧结果不得覆盖新项目，也不能因读取失败打开另一个目标。

关闭项目要先处理未保存内容，再结束它自己的终端和标签；
保存失败保留项目及编辑内容，规则见 [文件保存](file-saving.md#保存与关闭)。
停靠见 [Dock](dock.md)，系统窗口与投递见 [macOS 窗口](windows.md)。
