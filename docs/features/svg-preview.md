# SVG 矢量预览

`.svg` 默认显示图形。按 `⌘⇧V` 切换源码，文件标签右键可选择并排；
使用[文件查看路由](file-viewer.md)与同一原生文本缓冲。`.svgz` 不支持，请先解压。

## Invariants

- **按当前设备倍率绘制原矢量。** 不将整张 SVG 栅格化后放大，不为缩放另存大位图。
- **外部资源不加载。** 净化、引用展开和内嵌位图共用有界预算，不能执行内容。
- **无效编辑不破坏原文。** 保留最后有效画面并提示过期；导出只使用当前有效绘制版本，不替代源码保存。

## 支持与限制

SVG 支持同一文档中的渐变、剪裁、遮罩、滤镜，以及通过 `use` 复用的图形和 `symbol`。
不加载外部资源；支持同文档图案填充及继承、有界 PNG/JPEG 内嵌位图。
不支持的元素、外部图像和无效引用会被省略，独立预览会提示。
本地图形、渐变、图案、剪裁、遮罩和滤镜共用展开深度、8,192 节点与 1 MiB 字节预算；内嵌位图共用解码像素预算。超限时仍可查看源码。
独立 SVG 固有画布长边最多 32,768，宽与高的乘积最多 8,000,000；超过预览预算仍可查看和编辑原文。

## 矢量查看

独立 SVG 与 Markdown 共用净化器和 SwiftDraw；
原生滚动视图使用 SwiftDraw 在当前设备像素倍率绘制可见区域；平移、缩放、图案和导出共用同一图形坐标，不缓存整张缩放位图。
适应窗口会等比例放大较小的 SVG；手动缩放最高为原尺寸的 6400% 或适应窗口倍率的四倍（取较大值），
每次缩放按当前设备分辨率重绘原矢量，不放大 PNG。
切换标签、源码／预览、重挂载或同类型改名保留缩放和平移位置，实际文件替换后重新适应窗口。
实时源码修改合并为最新绘制请求；XML 暂时无效时保留最后一幅有效画面和位置，并显示过期标志与解析错误，直到新版本成功绘制。

共用平移、手势及基础 AX 见[图形视口](image-preview.md#缩放与平移)；SVG 使用本页的矢量缩放上限。

## 复制与导出

当前有效画布的右键菜单可复制或导出 PNG，明确选择像素尺寸、sRGB／Display P3 与透明或纯色背景。
输出保持宽高比，长边最多 32,768 像素，总计最多 800 万像素；导出只创建用户选择的新本地文件，不覆盖目标、不主动保存 SVG 源码。
从文件菜单或标签右键切回源码，仍可编辑原始 XML。无法显示的内容不写回文件。

## 验证

`SVGArtworkTests` 覆盖净化、引用、预算、真实矢量几何与 PNG 输出；
`PreviewScrollViewTests`、`SVGFilePreviewUITests` 验证实际视口、源码切换、并排及导出，
资源和保存共用验收见[测试规范](../testing.md)。
