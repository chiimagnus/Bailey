# 设置与恢复

修改配置、布局初始值、持久化或长期隧道时，保留以下约束。

## 配置

普通偏好与工作区初始值来自 `~/.config/kero/config.toml`，不是项目快照或未保存内容备份。设置由唯一的 `AppSettings` 状态管理；终端字体、配色、光标与 Option-as-Alt 变更由所属窗口及时应用到已有原生终端，不重建 Shell。

Kero 只有一个应用身份 `chiimagnus.kero`：配置目录固定为 `~/.config/kero/`，历史目录固定为 Application Support 下的 `kero/`。Debug 与 Release 使用同一身份和数据位置，不维护开发版 Bundle ID 或第二套配置目录。

显式 `--isolated-ui-test` 实例只隔离窗口快照与终端历史，并且不启动已保存隧道；普通配置仍是全局配置，因此隔离验收不得修改设置。

- 布局由窗口协调者显式传入项目；项目不自行读取全局布局配置。启动读取的初始值只影响新建项目，已有项目按保存布局恢复。
- 校验组数量、权重、选中项、工具唯一性与必需项；边缘范围为 `0.05...0.4`。无效工作区配置整体回退默认值并记录错误，不接受一半有效的布局。
- 保存偏好使用原子写入，并保留用户手工调整的工作区字段；失败不能破坏原文件。
- 不再读取旧字体 UserDefaults 或旧 `font-thicken` 键，现行键为 `terminal.font-thicken`。语言与 diff 偏好的现有 UserDefaults 不属于旧字体迁移，不能一并删除。
- 语言切换需重启，重启前保存窗口快照；翻译与回退行为见[本地化](LOCALIZATION.md)。

## 快照与恢复

窗口快照保存项目、独立标签内容、停靠布局、选择状态及编辑器光标/滚动位置。项目、标签、停靠、终端工作目录、文件路径及浏览器网址的实际更改触发 500ms 合并保存；这只用于窗口快照，与文件内容的失焦自动保存无关。普通界面刷新、Git 状态、终端命令状态与编辑器逐键输入不重复写盘。关闭窗口与应用退出立即保存最终状态。使用当前存储键和格式，不读取旧窗口快照，不增加旧格式解码或迁移；不主动删除用户原始快照。恢复时过滤无效停靠引用。

Info 面板已移除；旧配置中的 `info` 项和旧快照中的 Info 引用仅过滤自身，不回退整个布局，不丢其他面板、标签或分屏位置。

文件与 diff 重新读取，浏览器重新打开网址，终端启动新 Shell。快照不保存未保存文本、网页表单或运行中的进程，不能把重挂载保留状态等同于跨进程恢复。

终端历史回放默认关闭，启用后从独立文件恢复输出，不恢复进程。敏感输出边界见[安全](SECURITY.md)。

## 长期隧道

规则单独保存在 `~/.config/kero/tunnels.toml`，不能并入会被普通偏好重写的未知字段。

启用的隧道由应用级管理者启动与停止，不依赖某个终端标签。后台使用已有密钥或 SSH agent，不弹出密码认证；监听地址和端口必须校验，见[安全](SECURITY.md)。手动配置中不是整数或超出整数表示范围的端口只跳过对应隧道，不影响其余有效规则或启动。

## 验证重点

配置检查使用临时文件，覆盖默认值、往返、无效类型、手工布局保留与写入失败。恢复检查覆盖当前快照、单标签内容、上下文、历史与无效停靠引用；真实重启须区分可恢复状态与不能恢复的工作。验收隔离与正式应用替换统一按 [AGENTS.md](../AGENTS.md) 执行。
