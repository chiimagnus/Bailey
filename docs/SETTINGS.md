# 设置与恢复

按 ⌘, 打开设置，调整显示、输入和恢复方式。需要重启时，先保存编辑并结束不能中断的命令。

## 调整常用偏好

- **外观与颜色**：跟随系统或固定明暗模式，分别选择明暗主题。
- **语言**：修改后需要重启，设置页会提示；不会改变系统其他应用的语言。
- **字体与面板**：调整字体族、字号和面板字号；diff 和文件编辑器沿用工作区字体。
- **终端**：调整光标形状、闪烁、笔画加粗，以及是否把 Option 作为 Alt/Meta 发送给终端程序。
- **文本编辑**：启用编辑器自动换行；默认关闭，长行横向滚动。
- **Git**：切换目录树/列表布局；diff 的统一/并排选择在差异页顶部操作。

显示、终端、编辑与工作区配置保存在 `~/.config/kero/config.toml`。常用偏好可通过设置界面修改；工作区初始布局可直接编辑该文件。它不是项目、标签或未保存内容的备份。
“恢复默认设置”重置常用偏好，不应当作恢复文件或撤销 Git 操作的工具。

## 配置新项目的工作区

下面是默认值；未填写的键采用默认值：

```toml
workspace.groups = ["projects", "", "info,files,git"]
workspace.selected = ["projects", "", "files"]
workspace.weights = [0.12, 0.69256, 0.18744]
workspace.add-actions = ["session", "projects", "info", "files", "git"]
workspace.edge-threshold = 0.22
```

- `groups` 从左到右列出初始标签组，逗号分隔同组面板；空字符串表示暂时没有标签。一个工具在全部组中只能出现一次，且必须包含 `projects`。
- `selected` 指定每个组默认显示的面板；填空字符串时选该组第一个。`weights` 是对应组的相对宽度，可如 `[1, 3, 1]`。
- `add-actions` 控制每个标签栏「＋」的 Popover 选项及顺序，必须包含 `session` 和 `projects`。`edge-threshold` 控制拖入内容边缘时触发分屏的范围，允许 `0.05` 至 `0.4`。

配置在启动时读取，**只影响此后新建的项目**；已有项目的分屏和标签位置仍以项目保存的布局为准。无效工作区配置会整体回退默认值并写入系统日志。当前没有对外提供 API，但内部使用同一个类型化 `DockWorkspaceConfiguration`；未来接口可复用它，无须另建一套布局逻辑。

## 重启后恢复什么

Kero 保存每个项目的标签、自由停靠位置和分屏比例；重新打开文件、diff 和浏览器地址，并恢复文件编辑器的光标与滚动位置。默认三列只是新项目的初始布局。
文件和 diff 从磁盘或仓库重新读取，不恢复未保存的文字；网页也不恢复未提交表单或运行状态。

终端启动的是新 shell，不恢复运行中的命令或进程。“重启后恢复会话历史”默认关闭；启用后在新 shell 上方回放此前的终端输出。
输出可能包含敏感信息，启用前了解[保存输出的安全边界](SECURITY.md)。

## 端口转发

在“设置 → 端口转发”添加 SSH 主机、本地或反向转发方向及所需地址和端口，启用后查看规则状态。
启用的规则随 Kero 启动，不依赖某个终端标签；关闭规则或退出应用会停止相应隧道。
规则保存在 `~/.config/kero/tunnels.toml`，与普通偏好分开。

后台隧道使用已有密钥或 SSH agent，不弹出密码认证。连接失败时先检查主机别名、密钥、端口占用和规则错误。
转发的监听边界见[安全与漏洞报告](SECURITY.md)；不需要为了查看 SSH 项目文件额外创建隧道。

## 安全重启

1. 保存文件、可编辑 diff 和网页中的工作。
2. 结束不能中断的命令；需要持续运行的任务自行妥善托管。
3. 重启后确认项目、标签和布局恢复，再继续工作。

开发者替换应用时，安装签名与清理要求见[开发与验证](CONTRIBUTING.md)。
