# 文件与编辑器

修改树行、文件操作、编辑、读取或保存时，保留以下约束。

## 共享树与文件操作

文件、Git 工作区、暂存区和提交历史共同使用树模型与行组件，不各自实现交互。

- 压缩单子目录链，展开与目录操作指向真实末级目录；列表保持懒加载。
- 整行高亮范围可点击，包括缩进、上下边缘与留白；右侧按钮只执行自身动作，悬停行为在各使用方保持一致。
- 长名称可横向滚动，按钮不随内容移动；状态用名称颜色、提示及无障碍描述表达，不另设字母列。
- 展开状态按工作范围保留。重命名同步已打开文件的路径，后续保存写入新路径；删除边界见[安全](SECURITY.md)。

## 编辑与保存

文本、保存基线、光标与滚动位置由长生命周期文件标签保留，不由临时 View 持有。

- 未保存状态由当前文本与保存基线比较，撤销回原文必须清除标记。
- 仅干净文件可自动重载。读取结果核对路径与请求代次，不能覆盖读取期间的新编辑或更换后的工作区。
- 保存使用发起时的机器与内容；写入期间再次编辑仍保持未保存状态。失败保留内容并显示原因，不把错误当成保存成功。
- 关闭未保存内容提供保存、不保存与取消；保存失败不得继续关闭丢失编辑。断线与重连见[项目与 SSH](PROJECTS.md)。

## 格式与高亮边界

文本须可解码为 UTF-8，大小不超过 5 MiB；图片使用预览路径。超限、无法解码和读取失败须分别给出可理解的结果，不把容量上限当作性能保证。

沿用 STTextView/TextKit 与现有增量高亮。TSX 使用独立语法，Markdown/HTML 保留嵌入语言支持；未知语法退为纯文本，Markdown 不承诺排版预览。

字节、UTF-16 与行列坐标必须一致。样式更新不能修改文本、污染撤销或改变字体；高亮和读取的性能要求见[性能](PERFORMANCE.md)，第三方补丁见[依赖](DEPENDENCIES.md)。

## 验证重点

树改动一起检查四类使用方，覆盖窄面板、大字体、长名称、点击边界、键盘与无障碍。编辑改动覆盖保存失败、写入期间编辑、重命名、干净/脏文件重载、UTF-8 与大小边界、中文、emoji、CRLF、撤销及嵌入语言。
