# 文件与编辑器

从项目文件树打开文本，修改后按 ⌘S 保存；也可预览图片。

## 打开与整理文件

1. 选中项目，按 ⇧⌘E 打开文件面板。
2. 展开目录，点击文件打开编辑器；已打开的同一文件会回到原标签。
3. 需要与终端并排查看时，用右键菜单的“在旁边打开”。

右键菜单可新建文件或文件夹、重命名、复制路径及删除。重命名会同步已打开文件的路径，后续保存写入新路径。
本地删除移入废纸篓；[远程删除](PROJECTS.md#连接中断)不可依赖本机废纸篓恢复。

## 使用文件树

- 单子目录链显示为 `parent / child`，展开与目录操作指向真实末级目录。
- 高亮整行都可点击，包括缩进和留白；右侧按钮只执行自身动作。
- 长名称可横向滚动，操作按钮保持固定；文件面板按项目范围记住目录展开状态。
- 文件名颜色、提示与无障碍描述表示 Git 状态，含义见[文件状态](GIT.md#识别文件状态)。

## 编辑、查找与保存

- ⌘F 查找，⌥⌘F 查找并替换，⌘G 查找下一处；查找栏可用 ⇧↩ 回到上一处。⇧⌘G 用于 Git 面板，不是查找上一处。
- ⌘S 保存当前聚焦的文件；有未保存修改时，标签显示标记。撤销回保存内容后标记清除。
- 切换标签保留文本、光标和滚动位置。返回文件或切回 Kero 时，干净文件会检查磁盘变化；未保存内容不会被自动重载覆盖。
- 关闭未保存文件会询问保存、不保存或取消。保存失败会显示原因，并保留编辑内容。

长行默认横向滚动，需要自动换行时在[设置](SETTINGS.md)中启用。

## 高亮与限制

内置语法按文件扩展名或常见文件名识别，包括 Swift、JavaScript、TypeScript/TSX、Python、Rust、C/C++、HTML 和 Markdown 等。
Markdown 是源文本编辑，不是排版预览；带已支持语言标记的代码块可显示嵌入语言高亮。未知语法显示为纯文本。

文本需能解码为 UTF-8，大小不超过 5 MiB（5 × 1024 × 1024 字节）。不能解码或超限时显示说明；支持的图片类型使用图片预览，不进入文本编辑。
此上限不是流畅度承诺：长单行、密集语法和嵌入语言仍可能卡顿，调查方法见[性能](PERFORMANCE.md)。

SSH 断线后的编辑与保存见[项目与 SSH](PROJECTS.md#连接中断)。重启不恢复未保存文本，退出前先保存。
