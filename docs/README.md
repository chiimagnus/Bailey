# 使用 Kero

Kero 默认在左侧选项目、中间打开终端与编辑器、右侧查看文件、Git 和会话信息。三个区域都能拖动标签自由调整位置。
第一次使用：

1. 按[开发与验证](CONTRIBUTING.md)构建并安装本地签名应用。
2. 按 ⇧⌘A 添加本地文件或目录；SSH 项目从左下角“+”添加。
3. 选中项目，按 ⌘T 启动终端。
4. 按 ⇧⌘E 打开文件，或 ⇧⌘G 审查 Git 修改；编辑后按 ⌘S 保存。

## 添加项目

添加目录不会自动启动终端。连接要求、范围和断线处理见[项目与 SSH](PROJECTS.md)。

## 终端与分屏

终端、文件和浏览器可在标签内混合分屏；项目、信息、文件、Git 和工作标签也可跨区域停靠或上下左右分屏。拖到标签栏合并，靠近边缘分屏，拖动分隔线调节大小。⌘B 和 ⇧⌘B 隐藏或恢复左右停靠区。详见[终端与窗格](TERMINAL.md)。
