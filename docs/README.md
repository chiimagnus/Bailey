# 使用 Kero

第一次使用先[构建并安装](CONTRIBUTING.md)，再添加一个项目。
左侧选项目，中间使用终端、文件或浏览器，右侧查看文件、Git 和会话信息。

## 添加项目

- **本地**：按 ⇧⌘A，或点左下角“+”，选择一个或多个文件、文件夹。Finder 的文件夹服务也能添加项目。
- **SSH**：点“+ → 添加 SSH 文件或文件夹…”，选择 `~/.ssh/config` 中的主机别名，每行填写一个绝对路径。

SSH 使用已有配置和密钥，不需要挂载远程文件系统或为文件访问配置端口转发。
远端需有 POSIX shell 和 GNU 文件工具；Windows 使用 MSYS2 shell，路径可写为 `D:\GitHub\project` 或 `/d/GitHub/project`。
首次连接或主机信任失败时，先在终端用 `ssh 主机别名` 确认身份和连接。

添加目录不会启动终端。文件与 Git 跟随左侧选中的项目；关闭全部终端不会移除项目。
需要跨重启恢复远程文件标签时，把主机和路径添加为 SSH 项目，不只在本地终端里临时进入 SSH。

## 终端与分屏

选中项目后按 ⌘T 新建会话。本地项目打开本机 shell，SSH 项目打开远程 shell。
在“标签页”菜单中选择分屏方向；终端、文件、差异和浏览器可放在不同窗格。
按 ⌘F 查找当前终端或文件内容，按 ⌘P 打开命令面板，查找命令、文件或会话。
终端通知需授予 macOS 通知权限；点击通知可回到对应会话。

## 文件与 Git

按 ⇧⌘E 打开文件面板，⇧⌘G 打开 Git 面板，⇧⌘I 查看会话、进程和监听端口。
点击监听端口可在浏览器打开服务；远程端口会先转发到本机。

- 点击文件打开编辑器，按 ⌘S 保存。右键菜单可新建、重命名、复制路径或在旁边打开。
- 单子目录链显示为 `parent / child`，展开和目录操作指向真实末级目录。
- 高亮整行都可点击，包括缩进和留白；长名称可横向滚动，右侧按钮保持固定。
- 文件面板按项目记住展开状态；Git 按仓库记住目录折叠状态。

Git 面板分别显示未提交、已暂存和最近提交。点击文件查看差异；右侧按钮执行暂存、取消暂存或丢弃，不会打开文件。
可编辑的工作区文本差异支持修改和保存；暂存与历史差异只读。提交在 Git 面板完成，切换或新建分支用分支菜单；拉取、推送和储藏在“更多操作”菜单中。
在设置的“文件布局”中，可将 Git 的目录树切换为列表。

所有文件树用文件名颜色表示状态：修改为黄色，新增或未跟踪为绿色，删除为红色，重命名或复制为蓝色，冲突为紫色，忽略为灰色。
状态也出现在提示和无障碍描述中，不另设字母列。

## 浏览器

从“文件 → 新建浏览器标签页”打开浏览器，在地址栏输入网址。
网页链接的右键菜单可在新标签页或窗格中打开；也可交给系统默认浏览器。

## 设置与恢复

按 ⌘, 打开设置，可调整主题、语言、终端与侧栏字体、光标、编辑器换行和 Git 布局。
普通偏好保存在 `~/.config/kero/config.toml`，建议通过设置界面修改。

重启会重新打开 shell，不恢复运行中的命令。恢复终端历史默认关闭，可在设置中启用；启用前了解[输出保存的安全边界](SECURITY.md)。
改语言需重启生效；重启或替换应用前保存编辑并结束不能中断的命令。

需要长期 SSH 隧道时，在“设置 → 端口转发”配置本地或反向转发。
启用的规则随 Kero 启动，不依赖终端标签；规则保存在 `~/.config/kero/tunnels.toml`。

## 遇到问题

- 保存失败：查看编辑器或差异页的错误说明，检查权限与连接，不要先关闭未保存内容。
- SSH 断开：检查主机连接；远程编辑会暂时只读，重新连接后再保存。
- 远程删除：不会进入本机废纸篓，确认路径和备份后再执行。
- 疑似漏洞：按[安全与漏洞报告](SECURITY.md)私下联系维护者。
