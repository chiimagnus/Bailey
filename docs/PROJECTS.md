# 项目与 SSH

修改项目身份、工作范围或连接行为时，保留以下约束。

## 项目与面板范围

- 添加目录只创建项目，不启动终端；添加文件同时打开编辑器，以父目录作为工作范围。重复添加选中已有项目。
- 关闭全部终端或项目列表面板不删除项目；关闭项目是独立操作。
- 固定目录优先于终端目录。自动范围使用会话所在仓库；前台命令位于另一仓库或 worktree 时可跟随，同仓库子目录不切换根。
- 文件与 Git 以项目范围为准，不能随面板停靠位置改变。进程与端口操作还须匹配发起时的会话、连接及进程目标，不能仅凭 PID 相同执行旧动作。

## 机器与连接身份

路径不是完整身份。本机、不同远端、同主机不同 SSH 端口的同名文件与 diff 必须隔离；标签保留创建时的机器，不跟随当前终端改写目标。

SSH 项目使用既有 OpenSSH 配置与密钥，不要求挂载文件系统。远端命令以 POSIX shell 和 GNU 文件工具为前提；Windows 支持依赖 MSYS2 路径与 shell，不视为原生 Windows 命令。

- 异步根目录、文件和进程结果在发布或执行动作前核对项目与连接身份；切换目标后旧结果不得生效。
- 断线保留内容与未保存编辑，文件和可编辑 diff 暂时只读；同一机器重连可重新绑定，新连接不能接收旧请求结果。
- 远程读取或保存失败不得回退到本机同名路径。主机信任、删除和转发监听按[安全约束](SECURITY.md)处理。

## 验证重点

覆盖固定目录与自动范围、同仓库子目录与不同 worktree、同名路径的机器/端口隔离、切换目标后乱序结果、同 PID 的旧菜单动作，以及断线保存与重连。

受控后端只能证明目标隔离与失败处理；真实 SSH 传输需按 [AGENTS.md](../AGENTS.md) 使用专用测试连接验收。
