# 项目与 SSH

把常用文件或目录添加到左侧项目列表，切换项目时一起切换终端、文件和 Git 上下文。

## 添加本地项目

1. 按 ⇧⌘A，或点左下角“+”。
2. 选择一个或多个文件、文件夹。
3. 左侧出现项目；选择文件时同时打开编辑器，选择目录不会自动启动终端。

也可从 Finder 的文件夹服务添加项目。同一文件或目录再次添加时，会选中已有项目。
文件项目使用其父目录作为文件、Git 和新终端的起始范围。

## 添加 SSH 项目

1. 点“+ → 添加 SSH 文件或文件夹…”。
2. 选择 `~/.ssh/config` 中的主机别名。
3. 每行填写一个远程绝对路径，确认后加入项目列表。

Kero 使用已有 OpenSSH 配置与密钥，无需挂载远程文件系统，也无需为文件访问配置端口转发。
远端需有 POSIX shell 和 GNU 文件工具。Windows 使用 MSYS2 shell，路径可写为 `D:\GitHub\project` 或 `/d/GitHub/project`。

首次连接或主机信任失败时，先在终端运行 `ssh 主机别名`，核对身份并完成连接；不要关闭主机校验来消除报错。
需要跨重启恢复远程文件标签时，将主机和路径添加为 SSH 项目，不只在本地终端里临时进入 SSH。

## 看清当前范围

- 已指定目录的项目，文件与 Git 固定在该目录，不随终端 `cd` 改变。
- 未固定目录时，面板根据会话所在仓库确定范围；在同一仓库的子目录之间切换不会重新定位到子目录。
- 前台命令进入另一个仓库或 worktree 时，自动范围可能跟随该命令。文件面板的 `job` 或 `worktree` 提示说明了这种变化。
- 打开的文件与 diff 仍属于原来的机器和路径，不会因为切换项目而改写到另一台机器。

选中项目后按 ⌘T 启动[终端会话](TERMINAL.md)。关闭全部终端不会删除项目；明确关闭项目是另一项操作。
项目与标签的重启行为见[设置与恢复](SETTINGS.md#重启后恢复什么)。

## 连接中断

已打开的远程文件与可编辑 diff 会暂时只读，现有内容和未保存编辑保留。重新连接后再保存；读取或保存失败时，先查看页面上的错误，不要关闭尚未保存的内容。
远程删除不会进入本机废纸篓，操作前确认路径与备份，详见[安全边界](SECURITY.md)。
