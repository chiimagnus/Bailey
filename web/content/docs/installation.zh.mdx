Kero Remote 只从源码进行本地构建，不提供 DMG、Homebrew Cask 或自动更新。

## 本地构建与运行

需要 macOS 15.6+、Xcode，以及已安装在钥匙串中的个人 Apple Development 签名证书。

```sh
git clone --recurse-submodules https://github.com/chiimagnus/kero.git
cd kero
xcodebuild -project kero.xcodeproj -scheme kero -configuration Release \
  -destination 'platform=macOS,arch=arm64' -derivedDataPath build/DerivedData build
open 'build/DerivedData/Build/Products/Release/Kero Remote.app'
```

平时开发直接用 Xcode 打开 `kero.xcodeproj`，构建 **Debug** 即可。Debug 使用独立配置，
不会覆盖正式版数据。更多细节见[开发说明](https://github.com/chiimagnus/kero/blob/main/CONTRIBUTING.md)。

Release 使用本机 **Apple Development** 证书签名，未针对公开分发进行 Apple 公证。
替换 `/Applications` 中的版本之前，先退出旧 App，确认没有终端任务会被中断。

## 从 Finder 打开文件夹

将 Kero Remote 安装至应用程序并启动一次后，Finder 会在选中文件夹的 **服务** 菜单
中显示 **New Kero Remote Project Here**。如果没有出现，打开 **系统设置 → 键盘 →
键盘快捷键 → 服务 → 文件和文件夹** 启用它。

## 卸载

若启用了 **设置 → Automation → AI**，请先关闭该功能以清理已安装的 Agent 支持。
然后从「应用程序」删除 **Kero Remote.app**。如果还要清除保存的工作区和偏好设置：

```sh
rm -rf ~/.config/kero
defaults delete sh.kero.remote
```
