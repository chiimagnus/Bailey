---
title: Installation
description: Build Kero Remote locally, run it and remove it safely.
---

Kero Remote is built from source. There are no published DMGs, Homebrew casks
or automatic updates.

## Build and launch

Requires macOS 15.6+, Xcode and the personal Apple Development signing
certificate installed in your Keychain.

```sh
git clone --recurse-submodules https://github.com/chiimagnus/kero.git
cd kero
xcodebuild -project kero.xcodeproj -scheme kero -configuration Release \
  -destination 'platform=macOS,arch=arm64' -derivedDataPath build/DerivedData build
open 'build/DerivedData/Build/Products/Release/Kero Remote.app'
```

For a normal edit-and-run cycle, open `kero.xcodeproj` in Xcode and build the
**Debug** configuration (which uses separate settings). See
[developer instructions](https://github.com/chiimagnus/kero/blob/main/CONTRIBUTING.md).

The Release app uses your locally installed **Apple Development** certificate.
It is not notarized for public distribution. Before replacing a version in
`/Applications`, quit that app and make sure no terminal tasks will be interrupted.

## Open a folder from Finder

Once Kero Remote is installed and launched, Finder exposes the macOS service
**New Kero Remote Project Here** under **Services** for selected folders.
If it is missing, enable it in **System Settings → Keyboard → Keyboard Shortcuts
→ Services → Files and Folders**.

## Uninstalling

If **Settings → Automation → AI** is enabled, turn it off before deleting the
app to remove installed agent support. Delete **Kero Remote.app** from
Applications. To remove settings as well (this also deletes saved workspace
state), run:

```sh
rm -rf ~/.config/kero
defaults delete sh.kero.remote
```
